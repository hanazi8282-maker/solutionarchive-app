## 초안 문구

**수집 항목**
- 로그인 사용자: 매칭 리포트에 입력한 아이디어 원문 텍스트, 계정 이메일 주소, 입력 시각, 기록 구분(리포트 조회 · 앵글 검증 요청과 그 결과 — 새 실행 · 이전 결과 재사용 · 사용 한도 · 실패)
- 로그인하지 않은 방문자: 아이디어 원문 텍스트와 입력 시각만. **누가 입력했는지 알 수 있는 정보(이메일·IP 주소·쿠키·브라우저 정보·유입 경로)는 이 기록에 저장하지 않는다.**
- 참고: 아이디어는 주소(URL)의 일부로 전달되므로 호스팅 사업자의 접속 기록에 남을 수 있다(기존 화면 고지와 같다). 이 기록은 위 저장과 별개다.

**수집 방법**
- 방문자가 `/cases/report` 에서 아이디어를 넣고 리포트가 만들어질 때 서버가 자동으로 기록한다(로그인 여부 무관).
- 로그인 사용자의 리포트에서 앵글 검증이 실행될 때 한 번 더 기록한다(리포트 조회와 구분해 저장).
- 폭주 방지를 위해 짧은 시간에 요청이 비정상적으로 몰리면 일부 기록을 남기지 않을 수 있다.

**이용 목적**
- 창업자들이 어떤 주제를 고민하는지, 그 주제들의 비율이 어떻게 바뀌는지 분석해 서비스(케이스 수집 방향·기능 우선순위)를 개선한다(통계·분석 목적).
- 로그인 사용자가 같은 아이디어로 앵글 검증을 다시 요청하면 이전 결과를 바로 보여준다(7일).

**보관 기간**
