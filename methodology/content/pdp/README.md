## ⚠️ 이 아카이브의 특수성 — 두 번째 자료다

`solfa/`(유튜브 롱폼)에 이어 두 번째로 처리된 방법론이다. 그래서 이 폴더에는 **한 가지 축이 더 있다.**

```
solfa/04-decisions.md    R-01 ~ R-14   (유튜브 롱폼 / 개인 제작자 / 감상 중심)
pdp/04-decisions.md      P-01 ~ P-14   (인스타 릴스 / 마케팅 조직 / 전환 중심)
         ↓ 같은 질문에 다른 답을 하는 지점을 찾는다
../cross-decisions.md    C-01 ~ C-12
```

| 결과 | 의미 | 현재 건수 |
|---|---|---|
| **★ 도메인 불변 원리** (같은 답) | 매체·목적·시대가 달라도 통했다. 신뢰도 최상 | **3** |
| **🔀 조건부 규칙** (다른 답, 조건 확정) | "어떤 조건에서 갈리는가"가 새 규칙 | **5** |
| **⚔️ 미해결 충돌** (다른 답, 조건 미확정) | ★ 로그를 남길 최우선 대상 | **3** |
| **📤 고유 자산 / 결손** (한쪽만) | 전이 가능성 판정 | **1** |

> **핵심**: 두 전문가가 갈리는 지점은 이미 "조건에 따라 달라지는 문제"라는 강한 증거다. **내가 실패하지 않고도 조건부 규칙을 발견하는 장치**다.

### 루프 두 트랙

| 트랙 | 입력 | 학습 속도 | 잡아내는 것 |
|---|---|---|---|
| **정방향** | 내 발행 → 성과 | 1건 / 30일 | 내 판정이 **맞았는지** |
| **역방향 (G-R)** | 남의 터진 글 | 5건 / 세션 | 내 규칙에 **구멍이 있는지** ★ |

**권장 비율**: 발행 1건당 역방향 **5건 이상**(솔파는 3건). 근거 — **"정말 영상을 10시간 걸려서 하나를 만드는 것보다 잘된 영상을 10개 보고 스스로 분석을 해본 다음에 한 20~30분 걸려서 하나 만드는 게 훨씬 낫습니다."**

> 프드프에서 역방향은 부가 기능이 아니라 **방법론의 본체**다. §7-1: **"강의에서 얻어 가야 하는 게 딱 한 가지 있다면 그건 바로 이 분석하는 습관입니다."**
