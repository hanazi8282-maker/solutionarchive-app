# 조사 노트 — Juttu (juttu-nice-to-have-pricing-collapse)

큐 사유: failure_quota (실패·피벗·철수 사례 할당분, 성공 사례로 대체 금지)
대상 시장: SaaS · 1인/소규모 팀 소프트웨어
조사일: 2026-09-26

## 대상 선정

WebSearch로 "indie SaaS shutdown postmortem 창업자 1인칭 글"을 여러 각도로 훑어 후보
5곳(College Conductor, Juttu, RecoverFlow, Cydoc — 이미 적립 슬러그 있어 제외, MindWave/Super
AI/Vibe AI 3연속 실패)을 비교했다. 그중 **Juttu**를 선택한 이유:

- 창업자(Niko Noll) 본인이 자기 블로그(nikonoll.com)에 발행일이 명확한 1인칭 포스트모템을
  남겼다 — "사고의 흐름 1건 이상, 당사자 1인칭 출처" 요건을 가장 잘 충족.
- 구체적 수치(유료 고객 수, 목표치, 가격)가 있어 서술로만 남기지 않아도 됐다.
- 1인·소규모 팀(공동창업자 포함 소수, 3개국 원격) B2B SaaS — 이 배치의 시장 지정과 정확히 맞는다.
- 실패 원인이 하나가 아니라 최소 2개(가격/가치 불일치, 외부 API 의존 리스크)라 무브 2개를
  독립적으로 뽑을 수 있었다.
- 이미 적립된 슬러그 목록과 겹치지 않는다.

## 확인한 것

- **회사/제품**: Juttu — "B2B SaaS to automate recruiting and scheduling for Product Teams".
  창업자 Niko Noll(뮌헨 기반, XING/New Work SE 출신), 공동창업자 존재(인원수 미명시), 팀은
  3개국에 걸쳐 원격으로 운영.
- **문제 검증 → 커밋**: 2023년 6월, 문제 검증에 확신을 얻고 본업을 그만두고 MVP 개발에
  전념(1인칭 인용: "By June, we felt confident we had problem validation. We quit our jobs
  and committed to building an MVP.").
- **가격 구조와 실패**: 손익분기를 맞추려면 팀당 월 $200(전형적 조직 기준 월 $1,000)이 필요했다.
  창업자 결론: 고객들이 "아이디어는 좋아했지만 그 정도 돈을 낼 만큼 절실하지는 않았다."
- **고객 수 추이**: 2024년 5월 두 번째 유료 고객 확보, 9월까지도 목표(10곳) 중 단 2곳에 머묾.
  두 유료 고객은 실제로 제품을 좋아하고 정기적으로 썼다("Our two paying clients loved it and
  used it regularly") — 제품 자체가 안 통한 게 아니라 **가격이 감당할 만큼 절박한 문제에
  안 붙었다**는 게 핵심.
- **계약 직전 이탈**: 계약 임박 고객 3곳이 구조조정·레이오프·예산 동결로 전부 이탈.
- **Calendly API 의존 리스크**: 자체 일정관리 엔진 대신 Calendly API 통합으로 "영리하게
  가려던" 선택이 몇 달의 개발 끝에 Calendly의 오픈 API 이용약관 변경으로 통째로 막힘.
- **종료 발표**: 2024-11-28, 창업자 본인 블로그에 포스트모템 발행.

## 못 찾은 것 (확인 불가로 남긴 것)

- **정확한 창업 개시일**: "2023년 5~6월경"까지만 확인. 일 단위 날짜는 확인 못 해서
  `period_start`를 비워 뒀다(추측으로 채우지 않음).
- **공동창업자 인원수·이름**: 원문에 "co-founders"로만 언급되고 인원수·이름 불명. draft
  JSON에는 넣지 않았다.
- **독립 2차 출처(언론 보도 등)**: 이 정도 규모의 스타트업 종료를 다룬 제3자 보도를 찾지
  못했다 — 그래서 두 무브 모두 등급이 A가 아니라 C/D로 남는다(자기보고 1차만 있음).
  이건 정상이다: 근거 규칙상 "다른 원 관측"이 없으면 자기보고 1건만으로는 A가 나오지
  않는다. 억지로 제3자 출처를 지어내지 않았다.
- **juttu.co 도메인 관련 혼선**: 웹서치 중 juttu.co/about 페이지가 "cancel flows(해지
  방지)"를 다루는 다른 제품 설명을 내놓는 것을 발견했다 — 아마 도메인이 종료 후 다른
  용도로 재사용됐거나 별개 후속 프로젝트로 보인다. 접속 시도(WebFetch)도 503으로 실패해
  직접 확인은 못 했다. **이 초안은 창업자 본인의 2024-11-28 포스트모템 본문만 근거로
  삼았고, juttu.co의 현재 상태는 이 초안의 어떤 필드에도 반영하지 않았다** — 확인 불가를
  양성/음성 어느 쪽으로도 접지 않기 위함.
- **경쟁사·시장 상황**: 왜 '팀당 $200'이 구체적으로 산정됐는지(원가 구조, 목표 마진)는
  원문에 없어 조사 노트에만 남기고 무브의 claim에는 넣지 않았다.

## 무브·등급 요약

- **무브 0 (PRICING)** — 등급 A(독자 인사이트) / C(사실확인, 자기보고 1차뿐). transfer_note:
  관심 고객에게 실제 가격을 불러보고 "좋아요"와 "지금 결제하겠다"를 구분해서 확인하라.
- **무브 1 (PRODUCT_FEATURE)** — 등급 C(독자 인사이트) / D(사실확인, 수치 없음 — 서술만).
  transfer_note: 핵심 기능이 외부 API에 의존하면 ToS의 재판매·임베드 제한 조항을 확인하라.

두 무브 모두 `outcome_direction=negative`로 정직하게 남겼다. 억지로 긍정적 교훈으로
바꾸지 않았다 — 실패 자체(가격이 통증에 안 맞음, 외부 의존 리스크를 안 재고 시작함)가
독자가 가져갈 교훈이다.
