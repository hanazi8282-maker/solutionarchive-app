# 평가 세트 (Eval Set) — 정답이 알려진 30문항

> **성격**: 두 아카이브의 **실측 대조 사례**로 만든 문제집. 정답과 해설이 원문에 이미 있다.
> **위치**: `methodology/content/eval-set.md`
> **참조**: `solfa/01-methodology.md` / `pdp/01-methodology.md` / `00-gate.md` / `cross-decisions.md`

---

## 0. 이 파일이 존재하는 이유

게이트를 만들어도 **내 판정이 맞는지 알 수 없다.** D+30을 기다려야 하기 때문이다.

그런데 두 원문에는 **정답이 이미 알려진 대조 사례**가 수십 건 있다. 같은 조건에서 한쪽은 터지고 한쪽은 안 터졌고, **왜 그런지까지 원문이 분석해두었다.**

```
문항: [A안] vs [B안] — 결과를 가림
정답: 어느 쪽이 더 나왔는가 + 왜인가 (원문 분석이 정답지)
```

### 용도 3가지

| 용도 | 방법 |
|---|---|
| **① 내 판정 능력 측정** | 30문항을 풀고 정답률을 낸다. 오늘 당장 가능 |
| **② 스킬 품질 측정** | `solfa-gate` / `pdp-gate` 스킬에 문항을 던져 점수를 낸다. 스킬을 고쳤을 때 좋아졌는지 나빠졌는지를 감이 아니라 점수로 안다 |
| **③ 규칙 신뢰도 역산** | 특정 규칙(R-xx / P-xx / C-xx)이 걸린 문항에서 반복적으로 틀리면 **그 규칙을 내가 잘못 이해하고 있는 것** |

### 채점 방식

각 문항은 **2점**이다.
- **선택 1점** — 어느 쪽이 더 나왔는가
- **근거 1점** — 원문이 제시한 이유와 **같은 규칙**을 지목했는가 (표현이 달라도 규칙이 같으면 정답)

**만점 60점.**

| 점수 | 해석 |
|---|---|
| 54점 이상 (90%) | 두 방법론이 내면화됨. 게이트 없이도 판정 가능 |
| 42~53점 (70~89%) | 실전 투입 가능. 틀린 문항의 규칙을 재학습 |
| 30~41점 (50~69%) | 게이트를 반드시 돌려야 하는 단계 |
| 30점 미만 | 역방향(G-R) 세션을 먼저 20건 돌린다 |

> ⚠️ **선택은 맞았는데 근거가 틀린 경우가 가장 위험하다.** 우연히 맞힌 것이므로 재현되지 않는다.

## 1. 사용법

1. **정답을 가리고** 문항만 읽는다 (§3은 접어두거나 별도 파일로 분리)
2. 각 문항에 **선택 + 근거(규칙명)**를 적는다
3. §3에서 채점한다
4. 틀린 문항의 **규칙 코드**를 모은다 → 그 규칙이 내 약점이다
5. `04-decisions.md`에 약점 규칙을 기록하고, 다음 초안에서 그 규칙을 의식적으로 적용한다

**Claude에게 시킬 때**: 문항만 주고 답을 받은 뒤 §3으로 채점한다. 스킬 수정 전후 점수를 비교한다.

**A3. B** (20년 윈도우 유저, **162만**)

**A4. 갑** (해외판, 1670만)
- **근거**: **"이 같은 A와 B에서 연출을 다르게 해서 C가 갈라져 버렸다"**
- 결과 C: **"이 할아버지가 이 아이의 미래, 혹은 이 아이가 할아버지의 과거 요런 느낌까지"**

**A5. B** (길거리)
- **근거**: **"스튜디오에서 이렇게 책상에 앉히고 헤어 메이크업 다 하고 딱 말하는 순간 재미가 없어지는 거죠. 왜냐면 그 엉뚱함이 사라지니까."**

**A6.** 안 된다.
- **근거**: **"원래 이게 허접하게 보여야 되는데 간지가 납니다. 왜냐면 이게 이 아이가 이 음식을, 자기가 좋아하는 음식을 가지고 와서 몰래 집에서 혼자 찍는 느낌이 정말 강하게 들기 때문에"** / **"무조건 여기 위에 키네마스터가 붙어 있어야 됩니다."**
- 채점: "안 된다" 1점 / **허접함 자체가 진정성의 근거이며 제거하면 C가 무너진다** 1점

**A7. B**
- **근거**: **"'캡슐호텔에 갔다'가 아니라 '캡슐호텔에서 갔는데 뭐 뭐 했다'를 사람들한테 제시하는 거죠."** — B(행위)를 구체화
- 후속: 시장 말다툼 편은 **500만**

**A8. B**

- 프드프 용어로는 **권위 부여 + 언매칭**(§4-8, §3-13)

**A9. B** (7만 원)
- **근거**: **"제작비가 200만 원 넘게 나와요. 근데 조회수는 이게 더 잘 나와. 그리고 심지어 보는 사람들은 잘 몰라."**
- 규칙: 솔파 R-13(독자가 인지하는가) → C-10

**A10.** 해석: **"알고리즘은 결국 뚫림 (경험해보기 전까지는 모름)"** / **"결국 공유할 만한 컨텐츠를 만들면 뚫릴 수밖에 없다."**
- "버티면 된다"로 읽으면 안 되는 이유: **2년·억대는 개인이 감당할 수 있는 규모가 아니다.** 그리고 **뚫린 이유가 원문에서 명확히 분석되지 않는다**(`#검증필요`)
- 채점: 해석 1점 / 규모 또는 미분석 지적 1점

**A11.**
1. **시청 이유 없음** — **"심지어 여러분들이 인사담당자 그 직군에 있어도 그래도 아마 유튜브 피드에 '인사담당자가 된 이유' 뜨면 아마 안 볼 거예요."**
2. **알고리즘 이중 손해** — **"그거를 본 사람들이 없으니까 추천을 받기도 힘든"**
- 규칙: 솔파 R-11 = 프드프 표본 이론 → **C-01 불변 원리**

**A12.** 실패한다.
- **근거**: **"만약에 길거리에서 '돈 받고 그림 그려드립니다'하면 기대를 이미 하는 게 있으니까 당연히 저렇게 안 나오겠죠."**
- 핵심: **"예기치 못한 상황에서 자기를 섬세하게 그린 걸 봤을 때"**의 반응이 콘텐츠의 전부다. 기대가 생기면 목표 대사(**"주름이 왜 이렇게 많이 늘었지...?"**)가 안 나온다

**A13.**
1. **특이한 배경** — 뒤에 거대한 무언가
2. **1초의 법칙** — 눈을 흩날리며 시작
3. **유행하는 음악**
- **"이 세 가지 조건 중에서 두 가지가 빠지니까 하나는 1,400만 나오고 하나는 5만이 나오는 결과"**
- 채점: 3개 중 2개 이상 1점 / 3개 전부 2점

**A14. A**가 41/80/130만, **B**가 2~3만
- **근거**: 프드프 §1-9 — **"릴스에서는 검은색 부분이 절대 없어야 됩니다."** / **"조회수가 10만 나올 게 5천, 1만 이렇게밖에 안 나올 수 있다"**
- 원인: 릴스는 이미지 기반 플랫폼에서 진화 → 미적으로 안 예쁘면 알고리즘이 안 밀어준다

**A15. B** (110만)
- 이유: **표본.** 사이코패스를 찾고 싶은 사람은 적고, 김경일 교수는 전국적으로 알려져 있다
- **"엄청 대단한 카피는 아니지만 표본이 워낙 넓기 때문에 조회수가 100배 이상이 나온 겁니다."**
- 채점: 선택 1점 / **카피 품질보다 표본이 상위 변수** 1점

**A16. B** (498만)
1. **하위 욕망** — **"부모님에 대한 효도는 굉장히 하위 욕망이에요. (…) 생존과 번식의 관점에서"**
2. **공유 경로** — **"부모님이 이렇게 가버리면 부모님 중에 인스타 안 하시는 분들이 많기 때문에 공유가 일어날 확률이 적어지게 되는 거고, 결국 확률적인 관점"**
- 채점: 선택 1점 / 두 이유 중 하나 이상 1점

**A17.** 실질 **약 20배**
- 계산: **"해외에서 200만 나오면 사실 우리나라에서는 20만 나와야 정상"** → 33만의 한국 기대치는 3.3만. 실제 76만이므로 약 20배
- 원인: ① **추상어 제거**(부정적 감정 파괴 → 몸값 7.7배) ② **숫자의 원칙**
- 채점: 배수 1점 / 원인 1개 이상 1점

**A18.** **A4 용지를 이용한 비포/애프터**
- **근거**: **"A4 용지를 비포/애프터 형식으로 보여주는 게 500만씩 터지면서 브랜드가 확 올라갔거든요."**
- 규칙: 프드프 §6-3(비포애프터 — 차이가 클수록 좋다) + §12-2(얼굴 없이도 브랜딩)

**A19. C** (156만)
- A·B가 안 되는 이유: **표본.** **"네이버 지도 상위 노출에 관심이 있는 자영업자만 보는 거예요. 근데 매출을 높이고 싶은 자영업자는 100배가 많아요."**
- 추가: **"인스타그램 안에 올라가는 영상이다 보니까 '네이버 플레이스'라고 하면 표본이 더 낮아지게 돼요."**

**A20. C** (153만)
- **A**: 추상어. **"뇌에 아무런 충격이 가해지지 않고 숫자도 없고 각인되는 게 아무것도 없죠."**
- **B**: **목적어 부재.** **"1천만 원 아낀다는 건 좋은데 목적어가 없어요. (…) 이 영상을 누가 봐야 하는지가 명확하지가 않은 거예요."**
- C가 가진 것: 구체적 주어("나만 알고 싶은") + 숫자(2천만원) + 목적어(인테리어 비용)

**A21. B가 약 10배** (부동산 200~300만 명 vs 경제적 자유 2천만 명)
- **"만약에 부동산 책이 10만 부가 팔릴 책이었으면은 표본이 넓은 역행자라는 책은 100만 부가 팔리게 되는 거예요."**
- 대조: **부읽남(100만 유튜버)의 부동산 책** — 1주 종합 1등 후 하락 vs 역행자 **5주 연속 1등**
- 채점: 배수 1점 / 부읽남 대조 언급 1점

**A22.**
1. **320개 영상 중 3개만 남기고 전부 삭제** — 남긴 3개는 표본이 넓었던 것
2. **논문 근거 대신 전 국민이 볼 만한 콘텐츠**로 전환
- **"이런 형식으로만 가셔라 해가지고 쉽게 100만 유튜버가 되셨는데, 그게 표본 이론의 힘입니다."**

**A23.** 층위가 다르다.
```
콘텐츠 카피(알고리즘 확산) → 넓힌다
프로필 이름·소개글(검색 진입) → 좁힌다
```
- 근거: 검색하는 사람은 이미 **구매 의도**가 있으므로 경쟁도가 낮은 전문 키워드가 유리하다(§8-4). 알고리즘 확산은 관심 없는 층까지 뿌려야 100만이 된다(§1-5 5단계)
- 규칙: **프드프 P-03.** 실행 문장 — **"조회수는 넓히고, 검색 진입은 좁힌다."**
- 채점: 층위 분리 1점 / 각 층위의 이유 1점

**A24.** 자청은 **B**를 선호. 단점은 **100만까지는 안 나온다.**
- **"제가 하는 방식의 단점은 100만까지는 안 나와. 10만에서 100만 사이가 나오고, 이렇게 화면 변화가 많고 (…) 편집 많이 공들이게 되면은 확실히 100만 넘어갈 확률 자체가 높긴 해요. 그래서 장단점이 있습니다."**
- 규칙: 프드프 **P-08.** 선택 기준은 **목적**(전환 vs 조회수)

**A25.** 지점: **"이 모든 게 다 합쳐서 7만 6천 원"**
- **"저는 이 '7만 6천 원'에서 사실 게임이 끝났다고 봐요. (…) 와우 포인트가 나왔단 말이에요."**
- 앞에서 제거되어 있어야 할 의심: **비싸지 않을까 / 양 적지 않을까 / 특별할까 / 분위기 좋나 / 서비스 친절한가** — 그리고 대저택 입구, 남양주 정원, 톱스타 통대관, 코스 전 메뉴가 순서대로 이를 제거한다
- 규칙: 프드프 §5-7 + **C-12**(해소 구간 = 솔파의 달려가는 장면)

**A26.** 도입부가 **공장·가게 느낌이면 저조**, **가정집 느낌이면 잘 나옴**
- **"도입부가 좀 가게에서 찍은 듯한 느낌이 들면은 조회수가 잘 안 나오는데 이렇게 진짜 가정집 느낌에서 시작을 하는 영상들이 조회수가 되게 잘 나오고 있거든요."**
- 규칙: 소비자가 자기 상황에 대입할 수 있어야 한다 (프드프 §7-6 직관성)

**A27.** 문제: **셀링 포인트를 카피와 영상 어디에도 녹이지 않았다.**
- **"이렇게 가진 게 많은데 (…) 그 어디에도 그런 방금 얘기했던 어떤 셀링 포인트를 알 수 있는 문구나 장면이 하나도 없죠."**
- 셀링 포인트: **제주도 / 돌담이 우거진 넓은 독채 / 넓은 마당 / 반려견 입장 가능 / 바다 뷰**
- 처방: 카피에 "제주도 독채", "바다 뷰", 평수를 넣고 **카피와 매칭되는 영상**을 보여준다
- 채점: 문제 지적 1점 / 셀링 포인트 3개 이상 1점

**A28.** **같은 원리다.**
- 원리: **"콘텐츠는 그 주제에 이미 관심 있는 사람만 볼 수 있게 만들면 안 된다. 관심 없는 사람도 볼 이유를 만들어야 한다."**
- 분류: **★ 도메인 불변 원리** (`cross-decisions.md` C-01). 매체·목적·시대가 전부 다른데 같은 답 + **실패 사례의 형태까지 동일**
- 채점: "같다" + 원리 1점 / "불변 원리 / C-01" 1점

**A29.** 조건:

| 조건 | 답 |
|---|---|
| 기본기 미완성 / 이 분야 형식을 모름 | **프드프** (내 분야부터) |
| 내 분야를 다 봤다 / 차별화 단계 | **솔파** (다른 매체) + 프드프 해외 레퍼런스 |
| 형식이 포화된 카테고리 | 다른 매체 |
| 레퍼런스가 아예 없는 분야 | 인접 분야로 확장 |

- **상위 원칙**: **"아직 이 시장에서 소모되지 않은 형식을 가져온다."**
- 근거: 프드프의 **해외 레퍼런스**와 솔파의 **다른 매체**는 구조적으로 같다
- 채점: 조건 분기 1점 / 상위 원칙 1점

**A30.** 프드프의 처리:
1. **양으로 커버** — **"조회수 2,3000 정도만 나와도 되니까 (…) 일단 시작하는 게 중요합니다."**
2. **비용 최소화** — 템플릿 1분 제작. 실패해도 손실이 작다
3. **좁은 표본 전략** — 5천 조회수로도 매출(§12-1)

- **통하지 않는 경우**: **공수가 큰 콘텐츠.** 기획형 릴스(프리미어 편집·나레이션 녹음·프리미어 5분+)는 실패 비용이 크므로 "양으로 커버"가 성립하지 않는다
- 그래서 `00-gate.md` **P-9 / Ⅲ**에 솔파 R-08을 이식했다 (`cross-decisions.md` C-09)
- 채점: 처리 방식 1개 이상 1점 / "공수가 큰 콘텐츠에는 안 통한다" 1점

## 5. 확장 방법

이 세트는 **30문항이 끝이 아니다.**

### 5-1. 역방향 세션에서 문항을 추가한다
G-R로 분석한 남의 콘텐츠 중 **"내 게이트로 탈락시켰겠는데 실제로는 터진 것"**은 그대로 문항이 된다. 정답은 실측 조회수다.

```markdown
### Q31. [외부관찰 D-YYYYMMDD-nn]
[카피 A] vs [카피 B] — 어느 쪽이 더 나왔나?
정답: (실측) / 근거: (역방향 분석 결과)
```

### 5-2. 세 번째 자료가 들어오면
새 SEED와 기존 SEED가 갈리는 지점이 **교차 문항**이 된다. Q28~Q30이 그 형식이다.

### 5-3. 스킬 평가로 전환
`skill-creator`의 eval 형식으로 변환하면 자동 채점이 가능하다.
- 입력: 문항 텍스트
- 기대 출력: 선택 + 규칙 코드
- 채점: 규칙 코드 일치 여부

**스킬을 수정할 때마다 이 30문항을 돌려 점수를 비교한다.** 좋아졌는지 나빠졌는지를 감이 아니라 점수로 안다.
