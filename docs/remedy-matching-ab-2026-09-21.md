- **코퍼스**: 처방 카드가 실제로 보는 것과 같은 필드만. 선례 무브 28(승인·D등급 제외) · 실패 사례 22 · 원칙 32 = 82문서.
- **A 낱말 겹침**: 현행 `advise()` 그대로(기능어 제거 + 부분문자열 일치, 코퍼스당 상위 3).

## 3. 읽기
1. **둘 다 약하다.** 임베딩으로 바꿔도 카드의 4분의 3이 무관이다. 원인은 매칭 알고리즘이 아니라 **코퍼스 범위** — 질의는 탈모샴푸·유산균인데 선례 무브는 SaaS·DTC 매트리스·의류다. 뭘로 재도 짝이 없다.
2. 임베딩이 이기는 곳은 **선례 무브**(0.14 → 0.50). 낱말이 안 겹쳐도 "가격 대조 소구 ↔ 가격 불만"을 잡는다. 실패 사례·원칙에서는 이득이 없다.
3. 낱말 겹침의 0장 속성 2건(모발 굵기·두피 지속력)은 임베딩에서 관련도 2·0.33이 나왔다 — "관련 사례 없음"이 실은 "낱말이 안 맞았음"인 경우가 있다.
4. 판정자가 LLM이라 절대 점수는 믿지 않는다. 다만 같은 판정자가 블라인드로 본 상대 비교이므로 방향은 읽을 수 있다.

## 4. 결론 — 애매함, 전면 적용 설계 안 함
전면 적용의 조건("결과 뚜렷")을 못 채웠다. 남헌 판단 대기. 선택지:

- **(가) 코퍼스 확장 먼저** — 소비재(뷰티·건기식·생활용품) 케이스를 채우기 전에는 어느 매칭도 카드가 비거나 무관하다. 가장 싸고 확실.
- **(나) 하이브리드 2차 필터** — 낱말 겹침이 0~1장이거나 "신뢰도 낮음"뿐일 때만 임베딩(코사인 ≥0.60)으로 보충하고 그 카드에 "의미 유사" 배지. 선례 코퍼스에만 적용. 요청당 +0.5초, Gemini 쿼터 공유 리스크 인지 필요. 코퍼스 임베딩은 원장 sync 때 한 번만 계산해 테이블에 둔다(pgvector 또는 JSON 컬럼).
- **(다) 보류** — 현행 유지, 카테고리 태그 2차 필터(09-20 백로그 원안)로 오탐만 줄인다.

권고: (가) → 그다음 (나). (나)를 지금 넣으면 "의미는 비슷한데 도메인이 다른" 카드가 늘어난다.
