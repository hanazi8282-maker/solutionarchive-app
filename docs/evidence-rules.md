# 근거 규칙 — 출처 4축과 등급 산식

이 문서는 `scripts/case-research.mjs brief` 에서 **옮겨 온** 것이지 새로 만든 규칙이 아니다.
brief 가 독자 축(이식성)을 앞세우도록 재배치되면서, 길이가 긴 근거 규칙 전문이
1번 질문을 화면 아래로 밀어내고 있었다. 규칙 자체는 **한 줄도 완화되지 않았다** —
`lib/cases/draft.ts` 의 `validateDraft` 와 `gradeMove` 가 여전히 정본으로 강제한다.

> 등급을 2순위로 내린 것과 근거 기준을 낮춘 것은 다른 일이다.
> **선정 우선순위만 바뀌었고, 통과 기준은 그대로다.**

---

## 1. 출처는 4축이 서로 독립이다

| 축 | 뜻 | 흔한 함정 |
|---|---|---|
| `source_tier` | primary / secondary / tertiary | 공시는 반드시 primary (DB CHECK 가 막는다) |
| `is_self_reported` | 그 수치를 당사자가 말했나 | **창업자 인터뷰 = primary + self_reported** |
| `is_estimate` | 조사기관이 추정한 값인가 | 비상장사 매출은 대부분 여기 |
| `is_regulatory_filing` | 법정 공시(SEC S-1/10-K/8-K, DART)인가 | 허위기재에 법적 책임이 따르는 문서 |

추가 축 두 개:

- `is_issuer_defined_metric` — 공시 안에 있어도 발행사가 스스로 정의·집계한 운영 지표
  (DAU·활성고객수·ARPAC·NDR·재구매율). Nubank 20-F 가 본문에서 "not independently
  verified by any third party" 라고 밝힌 그 숫자들이다. `true` 면 A 등급의 전제가 깨진다.
- `observation_key` — 이 근거가 전하는 **원 관측**의 식별자. 10-K 원문과 그것을 받아쓴
  기사는 같은 키를 쓴다. 독립은 도메인이 아니라 이 키의 가짓수로 센다.
- `supports_metric` — 이 근거가 무브의 수치를 직접 받치는가. 기능의 존재·시기 같은
  서사만 받치면 `false`.

`observation_key` / `supports_metric` 의 `null` 은 **"확인하지 않았다"**이지
"아니다"가 아니다. 산식은 확인하지 않은 것을 독립으로 세지 않는다 (§7.1).

## 2. 출처를 찾는 순서

1. 상장사·공시 대상이면 **공시부터**. SEC EDGAR(S-1/10-K/8-K/주주서한), DART(감사보고서).
   - ⚠️ 듀오링고를 3차 블로그로 조사했더니 DAU 가 1600만→3000만이었는데, 8-K 에는
     1000만→2700만이었다. **틀린 숫자를 쌓을 뻔했다.**
2. 비상장이면 조사기관 추정치 + 무역·업계 매체. 추정치는 `is_estimate=true`.
3. 브랜드 자사 블로그·인터뷰는 마지막. 맥락에는 좋고 수치에는 약하다.

## 3. 등급 산식 (`lib/cases/draft.ts::gradeMove`)

```
A = 법정 공시 1개 (발행사 자체 정의 지표 제외)
  | 자동집계 공개 대시보드 자기보고 1차 1개 (비추정, config/open-dashboards.json 의 URL)
  | 비자기보고 1차 출처 1개
  | 서로 다른 원 관측 2개 이상
B = 자기보고 1차 출처 1개 + 다른 원 관측 1개
C = 근거는 있으나 위에 못 미침
D = 수치 자체가 없다 (서술만)
```

세지 않는 것:

- **3차 출처**(요약 블로그·해설 영상) — 원 수치를 옮겨 적은 것이라 독립 확인이 아니다.
  C 를 만드는 데는 쓴다.
- **추정치** — "Sacra 추정", "업계 추산", "~로 알려졌다". 아무도 실측한 적 없는 숫자다.
- **교차 확인에서 `supports_metric !== true` 인 행** — 개수를 세는 경로라 미기재를
  통과시키면 세면 안 될 것을 센다. (문서 성격을 보는 A 경로는 반대로 `false` 만 뺀다.)

`provisional: true` 가 붙은 등급은 "근거가 약하다"가 아니라 **"약한지 강한지 아직
안 적었다"**는 뜻이다. 둘을 같은 결과로 만들면 §7.1 위반이다.

## 4. 그 밖의 강제 규칙

- `published_at` 은 원문 게시일. 우리가 읽은 날이 아니다. 모르면 비우되 **비우기 전에
  한 번은 찾아봐라** — 시범 5건에서 근거 17건 중 11건이 게시일 미상이었고 대부분
  확인 가능했다.
- `snippet` 은 300자 이하(`SNIPPET_MAX`). 원문 전문 복사 금지 — 인용 분량이 실제 리스크다.
- 같은 보도자료를 받아쓴 기사 5개는 출처 1개다.
- **근거 0건 + 수치 있음 = `validate` 에서 error.** LLM 환각이 수치로 들어오는 경로가
  거기 하나뿐이다.

## 5. 발행 게이트

- **CG-1** — 등급 C 무브를 인용하는 초안은 본문에 출처 귀속 문구가 있어야 발행 대기로 간다.
  "업계에 따르면" 같은 얼버무림은 통과하지 않는다.
- **CG-2** — 등급 D 무브를 인용하는 초안 본문에 수치 표기(`\d+\s*(%|배|억|만원|명|x)`)가
  있으면 막는다(exit 4). D 는 정의상 수치가 없는 무브라, 그 글의 숫자는 우리 근거에서
  나온 게 아니다. 이식성 축이 `transferability='HIGH'` 인 D 무브를 앵글 후보로 여는
  문을 냈고, 이 게이트가 그 문에 붙는 자물쇠다.
