## 3. 방법론 아카이브의 설계 철학

### 3-1. 왜 만들었는가

원문(강의)에는 서로 충돌하는 진술이 많다. 여러 연도에 걸쳐 있고, 개인 제작자 시점과 조직 시점이 섞여 있기 때문이다. **어느 한쪽을 버리면 정보가 손실**되므로 둘 다 보존하고, 대신 **"언제 어느 쪽을 쓰는가"의 판정선**을 붙였다.

그런데 그 판정선은 **전부 원저자의 판단을 복사한 것**이다. 그래서 이 아카이브의 진짜 목적은:

```
[시작 상태]  R-01~R-14 / P-01~P-14 = 원저자의 판단 (SEED)
     ↓  발행 → 성과 대조 → 반증/보강 엔트리 누적
[6개월 후]   R-xx / P-xx = 남헌의 데이터로 덮여쓰인 나의 판정선
     ↓
[diff]      SEED와 현재 상태의 차이 = 오리지널리티의 정량적 좌표
```

솔파 원문의 정의를 그대로 구현한 것이다 — **"감이라는 건 결국, 내가 이렇게 했을 때 이 세상은 이렇게 반응하더라, 이런 상호작용의 관찰이 누적된 거거든요."** 이걸 무의식이 아니라 **버전 관리되는 파일**로 만든 것.

### 3-2. 절대 편집 규칙 (남헌이 지정, 모든 아카이브에 적용)

1. **압축·요약 금지.** 애매한 문장은 오히려 풀어서 세분화. 암묵적 전제·근거도 명시화
2. **구체적 수치·예시 문구·단계별 절차 일반화 금지.** 원문 표현 최대 보존 (**굵은 볼드 + 큰따옴표**로 원형 보존)
3. **모순은 하나 고르지 말고 둘 다 남기고 `#상충가능성` 태그**
4. **원문에 없는 내용 창작 금지** — 단, 후속 승인으로 근거 없는 보강도 허용됨. 이 경우 **반드시 `05-provenance.md` B-3에 등재**
5. 각 소분류는 **self-contained** + **4블록 필수**
   - ① 핵심 주장 (한 줄)
   - ② 근거/원리 (암묵적 전제까지 명시화)
   - ③ 원문의 구체적 예시·수치 (조회수·금액·장비명·실제 대사까지)
   - ④ 적용 시 주의사항/반례 (원칙이 깨지는 조건, 오독 위험)
6. 소분류 헤딩에 **원문 출처 마커** 부착

- 프드프: **"사이코패스를 찾고 싶은 사람이 그렇게 많지 않단 말이에요"** → 1만 → 110만
→ **여기서 떨어지는 초안은 다른 검토 없이 반려한다.**

**C-05 (첫 산출물)**
두 원문 어디에도 없는 통합 원칙을 도출했다.
> **"아직 이 시장에서 소모되지 않은 형식을 가져온다."**
> 초보 → 내 분야 안에도 안 쓴 게 많다 → 같은 분야부터 (프드프)
> 숙련 → 내 분야는 다 봤다 → 해외·다른 매체 (솔파 + 프드프 해외편)
> **두 방법론은 같은 원칙의 서로 다른 단계를 말하고 있었다.**

**C-09 (고유 자산 → 전이 실행됨)**
프드프에 솔파 R-08(하방선)에 해당하는 개념이 **아예 없다.** 프드프는 "낮은 비용"으로 처리하는데, 기획형 릴스(프리미어 편집·나레이션)에는 그 논리가 안 통한다.
→ `pdp/02-gate.md`에 **G-9 항목으로 이식**했고 `05-provenance.md` B-3-6에 "원문에 없음" 명시.

### 7-5. 미해결 충돌 3건 — 로그 최우선 대상

| # | 조건 초안 (미검증) |
|---|---|
| **C-02** | 변수가 적은 매체 → 공식으로 상위권 / 변수가 많은 매체 → 공식은 하한선만. **재현성 층위가 다름**(솔파=시리즈 실패, 프드프=단발 성공)이라 서로 반증하지 않을 수 있음 |
| **C-04** | **품질 전제는 양쪽 합의.** 그 위의 조작만 갈림. 프드프 내부에서도 P-13으로 충돌. **실측 설계**: 같은 품질 10건 중 5건은 업로드 직후 반응 작업, 5건은 무작업 → 초기 도달 비교 |
| **C-06** | **다른 종류의 위험을 다룸.** 솔파=타인 인격(윤리) / 프드프=소비자 기만(법·신뢰). **둘 다 필요.** 통합 판정선 초안: ①타인 등장→R-14 ②내가 광고주체→P-14+출처표기 ③둘다→더 엄격한 쪽 ④공통 최저선: 사실은 실제여야 |

### 7-6. 세 번째 자료가 들어올 때

```
2개  → "두 사람이 갈리는 지점"  (조건부 규칙의 증거)
3개  → "2:1로 갈리는 지점"      (소수설이 어떤 조건에서 옳은지가 규칙)
4개+ → 어느 한 사람의 것도 아닌 문서 = 이 아카이브의 오리지널리티
```
절차: ①C-01~C-12에 **새 열 추가**(기존 판정 삭제 금지) ②3자 동일 → 불변 원리 승격 ③**2:1로 갈리면 소수설이 옳은 조건을 찾는다 — 가장 값진 규칙** ④새 자료 고유 개념은 고유 자산 등재 ⑤종합 표 집계 갱신

## 8. 통합 게이트 `00-gate.md`

### 8-1. 왜 필요했나

솔파 게이트와 프드프 게이트를 초안 하나에 둘 다 돌리면 중복이 크다. 그런데 그냥 합칠 수도 없다 — 같은 질문에 다른 답을 하는 지점이 있기 때문이다. `cross-decisions.md`의 판정 결과가 이 문제를 푼다.

### 8-2. 4단계 구조

```
[Ⅰ] 공통 관문   ← C-01, C-08, C-12 (불변 원리 3건)
        ↓        여기서 떨어지면 매체 무관 폐기
[Ⅱ] 조건 분기   ← C-03, C-05, C-07, C-10, C-11 (조건부 5건)
        ↓        어느 쪽 규칙을 쓸지 결정
[Ⅲ] 매체별 게이트 ← solfa/02-gate.md 또는 pdp/02-gate.md (한쪽만)
        ↓
[Ⅳ] 충돌 로깅   ← C-02, C-04, C-06 (미해결 3건)
[Ⅴ] 로그 기입
[Ⅵ] 역방향 — 양쪽 게이트를 다 돌린다
```

**Ⅰ. 공통 관문 3항목**
- **U-1** 타깃 — 이 분야에 관심 없는 사람도 볼 이유가 있는가 `[C-01]`
- **U-2** 구조 — 달려가는 지점 = 해소 구간이 하나로 특정되는가 `[C-12]`
- **U-3** 관찰 — 이 판단이 관찰에서 나왔는가 `[C-08]` (초안 검증이 아니라 **주 1회 습관 점검**)

**Ⅱ. 조건 분기 5개**
- **D-1** 초반 몇 초를 얼마나 조일 것인가 → **Threads 기본값 = 프드프**(스크롤 피드)
- **D-2** 레퍼런스를 어디서 → 통합 원칙 적용
- **D-3** 현실 연결 검증 → 3단계 (프드프 3욕구 → 솔파 사후정당화 차단 → 프드프 근원이득)
- **D-4** 시간을 얼마나 → 2단 판정선 (①독자가 인지하는가 ②도달인가 전환인가)
- **D-5** A에 어떤 라벨 → 권위+계층 결합 가능(=언매칭)

**Ⅲ. 매체별 라우팅**
| 산출물 | 게이트 |
|---|---|
| Threads·릴스·쇼츠·숏폼·세일즈카피·랜딩 | `pdp/02-gate.md` G-0~G-13 |
| 유튜브 롱폼·영상기획·인터뷰·브랜디드 | `solfa/02-gate.md` G-0~G-10 |
| 블로그 장문·뉴스레터 | 혼합 — D-1에서 결정 |
| PB 브랜드·제품 기획 | 양쪽 부록 전이 항목 병행 |

**중복 제거**: Ⅰ에서 본 항목은 Ⅲ에서 건너뜀 (pdp G-3·G-7 / solfa G-2·G-4)

**Ⅵ. 역방향 — 핵심 판정 2개**
```
□ 솔파 게이트로 이 글을 탈락시켰겠는가?
□ 프드프 게이트로 이 글을 탈락시켰겠는가?
```
| 결과 | 처리 |
|---|---|
| 둘 다 통과 | 신뢰도 +1 |
| 둘 다 탈락 | ★ 양쪽 공통 구멍 |
| **한쪽만 탈락** | ★★ **조건부 규칙의 증거** — 단일 게이트로는 원리적으로 발견 불가 |

## 9. 평가 세트 `eval-set.md`

### 9-1. 왜 필요했나

게이트를 만들어도 **내 판정이 맞는지 알 수 없다.** D+30을 기다려야 하기 때문이다. 그런데 두 원문에는 **정답이 이미 알려진 대조 사례**가 수십 건 있고, **왜 그런지까지 원문이 분석**해두었다.

1. **내 판정 능력 측정** — 오늘 당장 가능

3. **규칙 신뢰도 역산** — 특정 규칙에서 반복 오답 = 그 규칙을 잘못 이해 중
