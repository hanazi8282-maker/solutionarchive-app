# Kite 조사 노트 — 2026-10-10 (실패 사례 할당분)

## 선정
- 대상이 "미정"이라 직접 골랐다. 실패·종료 사례. 적립 목록과 겹치지 않는 축: "무료로 사용자는 모았는데 개인은 돈을 안 냈다 + 수익화를 맨 마지막에 뒀다."
- 가까운 기존 케이스: `growrecruit-…` (무료 베타 → 유료 벽에서 이탈). 차이: Kite 는 투자받은 약 15명 팀이고 사용자 50만 명, 구매자와 사용자가 다르다는 점(팀장)이 핵심이다.
- 한계: Kite 는 소규모 1인 사례가 아니다. 그래서 transfer_note 를 "내 사용자 중 회사 메일 5명에게 묻기", "없으면 뭐가 안 되나 3명에게 묻기", "가격을 오늘 1명에게 보내기"로 1인 규모에 맞게 줄였다.

## 사고의 흐름 (1인칭)
- Adam Smith 종료 글(2022-11-20): "개인 개발자는 도구에 돈을 내지 않는다 → 팀장은 낼 수 있어도 확실히 새로운 기능에만 낸다 → 코딩 속도 18% 향상은 와닿지 않았다." 관찰(50만 명이 쓰는데 매출 없음) → 추론(구매자는 개인이 아니라 팀장) → 결론(속도 향상은 별도 기능으로 안 팔림)이 이어진다.
- **원문을 직접 열지 못했다(확인 불가).** `kite.com` 은 지금 도메인 매물 페이지다. 웹 아카이브는 도구가 막았고 GitHub README 는 504/404 였다. 그래서 같은 글을 인용한 DevClass(2022-11-21), Silicon Republic(2022-11-22), Slashdot·AI Business 요약에서 문장을 확인했다. 모두 같은 원 관측이라 `observation_key` 를 같게 했다. 규정상 "1인칭 직접 열람 1건"은 **조사 미완 항목**으로 남는다.
- 보강 1인칭: TechCrunch 2019-01-28 투자 기사에서 창업자가 "수익화보다 성장에 맞춘다"고 말했다(기자가 옮긴 발언).

## 못 찾은 것 / 확인 불가
- 유료 전환 수, 매출, Kite Pro 가격: 원문에 없거나 확인 못 했다. (한 요약 도구가 "$10/월"을 냈으나 Copilot 가격과 섞인 문맥이라 **쓰지 않았다**.)
- "Kite Pro 기능 대부분이 무료 버전에도 있었다"는 검색 요약 한 줄은 원문 대조를 못 해서 **초안에 넣지 않았다**.
- 총 투자액, 정확한 직원 수(약 15명은 DevClass 한 곳), 종료 직전 월 매출: 확인 불가.
- price_band: 가격을 확인 못 해 비웠다.
- `outcome_status=shutdown`: 종료·오픈소스 공개는 다수 언론이 보도했다. 지금 서비스가 돌고 있지 않은 것은 도메인 상태로도 일관된다.

## 교훈을 억지로 만들지 않은 부분
- 창업자는 실패의 큰 원인을 "기술이 10년 이상 일렀다"로 꼽았다. 돈 문제만으로 환원하지 않았다(summary 와 move 2 에 명시). 1인 창업자가 옮길 수 있는 건 "누가 돈을 낼지 먼저 묻기" 부분뿐이다.
- 모든 무브는 `outcome_direction=negative`, 등급 D(수치 없음, 서술만). 발행 불가·사내 참고용이 정상이다. 50만 명 숫자는 metric 이 아니라 서술로만 넣었다.

## VOC
- VOC 해당 없음. `ops/state/voc-inputs/index.md` 에 Kite 프로젝트가 없다(가까운 SaaS 개발자 프로젝트인 Tailscale·PostHog·Cal.com 은 다른 회사 후기라 붙이지 않았다). `voc_inputs` 는 비워 뒀다.
