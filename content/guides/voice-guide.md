# 보이스 가이드 — 사용자 문체 지문
> 이 글의 **원작자(사용자) 고유의 목소리**를 정의한다. 첨삭 시 이 목소리를 **반드시 보존**한다. 일반적인 'LinkedIn 인플루언서 톤'으로 덮어쓰지 말 것. 첨삭은 구조·훅·전달력만 손보고, 화자의 인격·리듬·어휘는 그대로 둔다.

## 한 줄 정의
**"개인적 경험에서 출발해 → 실패와 깨달음을 솔직하게 고백하고 → 하나의 통찰(thesis)로 수렴시키는, 차분하지만 확신에 찬 1인칭 화자."**
- 화자는 항상 현장에서 직접 겪은 '나'. 관찰자가 아니라 당사자.
- 가르치지 않는다. "나도 몰랐다 → 깨달았다 → 당신도 그럴 것이다"의 동행자 톤.
- 똑똑함을 자랑하지 않고, **실패와 무지를 먼저 드러내며** 신뢰를 산다.

## 말투·어조
- **1인칭 '저/제'** 고정. 화자가 직접 보고 겪은 일만 서술.
- **합쇼체('~습니다/~입니다')가 기본**이되, 구어체 어휘로 풀어 딱딱하지 않게.
- 강연이 아니라 커피챗 거리감. 과장된 흥분 금지, 감정은 절제해서 얹음.
- 겸손한 확신: 단언하되 자기 한계를 솔직히 인정("여전히 어렵습니다").

## 문장 끝맺음 (빈도순으로 섞어 쓸 것)
- `~습니다 / ~입니다` (기본, 80%)
- `~죠` (동의 구하기·가벼운 마무리)
- `~까요? / ~걸까요? / ~할까요?` (수사적 질문, 단락 전환)
- `~더군요 / ~하시더군요` (관찰·깨달음·전해 들은 말 보고)
- `~버렸습니다` (이미 벌어진 일의 무게 강조)
- ❌ 평어체('~다')로 글 전체를 끌지 말 것. 평어는 한 줄 강조 문장에서만 예외.

## 문장 호흡
- **장단 교차:** 긴 설명 뒤 한 줄짜리 짧은 단정. ("답은 '영향력'이었습니다.")
- **한 문장 = 한 단락:** 핵심 주장·전환점은 앞뒤 빈 줄로 독립.
- **3단 리듬 / 점층·감소 숫자 (시그니처):** "50분 동안 서버가 마비되었고, 30초에 한 번씩 CS 전화벨이 울렸으며, 5초에 한 번씩 뒷골이 당겼습니다."
- 단락은 2~4문장, 사이에 빈 줄 넉넉히.

## 자주 쓰는 어휘 (적절히 섞으면 톤이 산다)
- 깨달음/전환: `문득`, `사실`, `솔직히`, `정확히는`, `오히려`
- 구어 동사: `툭 던졌죠/던진`, `갈아 넣었던/갈아 넣은`, `말아먹었다`, `허우적거리다`
- 의성어(절제, 1~2회): `우당탕탕`, `어쩌구 저쩌구`
- 호칭: 협업자·동료는 반드시 `님`. 레퍼런스는 실명 직접 호명(나이키, 레드불, 현우진).
- 커뮤니티어: `찐팬`, `영향력`, `자산`

## 서사 아크 (거의 모든 글이 따르는 골격)
1. **과거의 나** (무지/실패/오만) — "이 사고방식이 문제였습니다."
2. **전환 사건** (미팅/대화/일화) — 실제 대화를 따옴표로 재현. (상대 발언 `" "`, 속생각 `' '`)
3. **깨달음** — "문득 생각이 들었습니다." / "답은 ___였습니다."
4. **일반화된 통찰** — 개인 경험 → 보편 법칙. "브랜딩 = 고객경험이다."

## 도입부 패턴 (택1)
- 결과/숫자 충격형 (최다): "이틀 만에 700만원을 벌었습니다."
- 내면 독백 질문형(따옴표): "'CEO들은 대체 어떻게 돈을 벌어오는 거지?'"
- 장면/일화 진입형: "지난 여름, 계획도 친구도 아무것도 없이 우당탕탕…"
- 도입 직후 반전 자문: "천재였을까요? 전혀 아니었습니다."

## 마무리 패턴 (택1, 한 줄로 끊는다)
- 선언/예언형: "그 시대는 이미 시작된 것 같습니다."
- 테제 반복형: "콘텐츠는 자산입니다."
- 독자 직접 질문형: "당신만의 스토리를 만들고 계신가요?"
- 커피챗 권유형: "편하게 커피챗 남겨주시면 감사하겠습니다."

## 수사 장치
자문자답 / 반전 부정("~였을까요? 전혀 아니었습니다") / 자기 폄하 후 반전 / 권위 차용(유명 브랜드·인물) / 취약성 노출.

## Do / Don't (보이스)
**Do:** 1인칭 유지 · 실패 먼저 고백 · 짧은 단락+빈 줄 · 핵심은 한 줄 독립 · 협업자 `님` · 마무리 한 줄 선언.
**Don't:** 평어체로 전체 끌기 · 정의·배경으로 시작 · 직접적 자기 자랑 · 느낌표 남발 · 한 단락 5문장 초과 · 마무리 장황한 요약.
