야간 자율 운영 모드. 입력을 세미콜론으로 분해해 작업 큐로 만든다: $ARGUMENTS

큐의 각 항목에 대해 순서대로 /feature 루프를 돌린다. 단:
- 모든 작업은 preview/feat 브랜치에서만. 어떤 것도 자동 머지·prod 반영하지 않는다.
- 🔴 리스크 항목은 구현하지 말고 "승인 대기"로 표시만 한다.
- 한 항목이 4회전 내 실패하면 큐에서 빼서 "에스컬레이션"으로 모으고 다음 항목 진행 (전체 중단 금지).

모든 항목 종료 후 @reporter 로 단일 종합 보고:
- ✅ 머지 대기 PR (기능명 + 리스크등급 + PR url)
- ⏸ 승인 대기 (🔴 사유)
- ⚠️ 에스컬레이션 (실패 사유)
