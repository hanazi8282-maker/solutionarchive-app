# 02. 검증 게이트 (Gate)

> **성격**: 이 파일은 읽는 문서가 아니라 **통과시키는 절차**다. 초안 하나당 1회 실행.
> **파일 지도**: `README.md` / `01-methodology.md` / **`02-gate.md`(현재 파일)** / `03-excerpts.md` / `04-decisions.md` / `05-provenance.md`

---

## 0. 사용법

1. 초안을 놓고 아래 항목을 **순서대로** 묻는다. 순서에 의미가 있다 — 앞에서 떨어지면 뒤는 볼 필요가 없다.
2. **떨어지면 고치는 게 아니라 돌아간다.** G-1에서 떨어졌는데 문장만 다듬는 것이 가장 흔한 실패다.
3. 규칙 충돌이 발생하면 `04-decisions.md`의 R-01~R-14를 적용하고, **적용한 순간 판정 로그 엔트리를 만든다.**
4. 예외 통과(떨어질 뻔했는데 통과시킴)는 반드시 로그에 남긴다. 그게 나중에 신규 규칙이 된다.
5. **역방향 모드(G-R)** — 남의 터진 콘텐츠를 넣으면 "왜 터졌는지"가 역산된다. 정방향보다 회전 속도가 10배 빠르다.

## G-1. 존재 이유 — "이걸 왜 봐야 하는데?"

> 솔파가 불문율이라고 부른 항목. 나머지 전부보다 우선한다.

| 확인 | 근거 |
|---|---|
| □ **나라면 이걸 볼 것인가?** — 3번 물었는가 | §2-9 |
| □ **이 글의 행위/주장이 독자의 현실과 어떻게 맞닿아 있는가**를 한 문장으로 쓸 수 있는가 | §2-10 |
| □ 그 현실은 **"이 아이디어가 나오기 전에 있었던 것"**인가 (사후 정당화가 아닌가) | §2-10 |

**원문 경고**
> **"여러분들 얼굴을 거울로 보면 재밌지만 1시간 동안 볼 수 있죠. 여드름 하나 갖고 1시간 동안 만질 수 있잖아요. 남들은 그렇게 못하죠, 똑같습니다 영상도."**

**떨어졌다면** → 폐기하거나 §3-7(쥐어짜기 절차)로 되돌아간다. 문장 수정으로는 절대 해결되지 않는다.

## G-2. 타깃 — 좁히고 있지 않은가

| 확인 | 근거 |
|---|---|
| □ **이 분야에 관심 없는 사람도 볼 이유가 있는가** | §2-13, R-11 |
| □ 조건을 곱하고 있지 않은가 (X에 관심 있고 + Y도 알고 + Z까지 겪은 사람만 이해) | §2-13 |
| □ 소재가 마이너한 건 괜찮다. **그 업계 사람만 이해하는 글**이 아닌지만 본다 | R-11 |

**원문 반례**
> **"'난 인사담당자야' 하면서 막… '꿀팁!' (…) 난 세상 밖은 안 볼 거야 이렇게… 여기만 보고 있는 거야, 계속. (…) 그러면 안 됩니다. 이거를 여세요."**

**떨어졌다면** → §2-13의 확장 4가지(계층 변화 / 역할 반전 / 대상 교체 / 관계 도입)를 대입해본다.

## G-R. 역방향 모드 — 남의 콘텐츠 리버스 엔지니어링

> **정방향**: 내 초안 → 통과/탈락
> **역방향**: 터진 남의 콘텐츠 → **왜 터졌는지 역산**
>
> 게이트 항목은 대칭이다. 질문의 방향만 뒤집으면 된다. 솔파 §1-10(**"저는 진짜 몇천 개 읽어요"**)이 정확히 이 작업이며, 지금까지 감으로만 남던 것을 구조화된 산출물로 만든다.

### 왜 하는가 — 루프 회전 속도

내 발행만으로는 **한 번에 1건씩**밖에 학습되지 않는다(D+30 대기). 역방향은 **하루 10건도 가능**하다. 그리고 세 가지 교차 신호가 나온다.

| 교차 | 의미 | 가치 |
|---|---|---|
| 내 판정 ↔ 남의 **성공** 패턴이 **어긋남** | 내가 틀린 곳 | 높음 |
| 내 판정 ↔ 남의 **실패** 패턴이 **일치** | 내가 이미 아는 곳 | 낮음 (확인용) |
| 남은 성공했는데 **내 게이트로는 탈락시켰을 글** | ★ **규칙에 구멍이 있는 곳** | **최고** |

세 번째가 이 모드의 존재 이유다. 정방향으로는 절대 발견되지 않는다 — 탈락시킨 글은 발행되지 않아 데이터가 남지 않기 때문이다.

### 대상 선정 기준

| 선정 | 제외 |
|---|---|
| 내 영역과 **인접**하되 내가 안 쓸 것 같은 글 | 이미 내가 잘 아는 포맷 |
| 이유를 **모르겠는데 터진** 것 ★ | 이유가 뻔한 것(팬덤·시의성 폭발) |
| 내 취향이 아닌 것 (§2-15 **"저는 전혀 안 보는 육아를 보고 있어"**) | 광고·협찬 등 외부 트래픽 유입 건 |

⚠️ **팬덤 도달은 제외한다**(R-05). 유명해서 터진 건 학습 재료가 아니다.

### 역방향 질문표

정방향 항목을 그대로 뒤집는다.

| 항목 | 정방향 (내 초안) | **역방향 (남의 글)** |
|---|---|---|
| **G-0** | 이 글의 C를 한 줄로 말할 수 있는가 | **사람들이 이 글에서 무엇을 느꼈나** — 댓글·인용문에서 추출한다. 내 해석이 아니라 **반응의 실물**에서 |
| **G-1** | 나라면 볼 것인가 | **사람들이 이걸 왜 봤지?** 이 글의 행위/주장은 **어떤 현실**과 맞닿아 있었나 |
| **G-2** | 타깃을 좁히고 있지 않은가 | 이 글은 **어느 계층까지 닿았나.** 그 분야 사람이 아닌데 반응한 사람이 있나 |
| **G-3** | 첫 문장이 반례인가 | 첫 3줄이 **무엇을 뒤집었나.** 통념을 명시적으로 쓸 수 있나 |
| **G-4** | 달려가는 장면이 있는가 | **어느 문단이 잘려서 인용됐나.** 그게 이 글의 콘텐츠 각이다 |
| **G-6** | 퍼갈 이유가 있는가 | **실제 인용문에 뭐라고 쓰여 있나** — 이게 §2-9 4번의 실측치다 |
| **G-9** | 각색의 선을 넘지 않았는가 | 어디까지 각색한 것으로 보이나. **독자가 거부반응을 보였나** |

### 핵심 판정 — 내 게이트로 이 글을 탈락시켰겠는가

역방향 분석의 **마지막이자 유일하게 중요한 질문**이다.

```
□ 이 글을 내가 썼다면, G-0~G-9 중 어디서 떨어뜨렸겠는가?
   → 떨어뜨릴 곳이 없다  = 내 규칙과 정합. 신뢰도 +1
   → 떨어뜨렸을 곳이 있다 = ★ 규칙에 구멍. 신규 규칙 후보 NEW-xxxx 생성
```

떨어뜨렸을 항목이 나오면 **반드시** `04-decisions.md`의 `## 5. 신규 규칙 후보`에 적는다. 3회 반복되면 R-15 이후로 승격.

### 실행 절차

1. 대상 3~5건을 고른다 (한 세션 기준)
2. 각 건에 대해 역방향 질문표를 채운다 — **댓글·인용문을 실제로 읽는다.** 내 추측으로 채우면 아무 의미가 없다
3. 핵심 판정(탈락 여부)을 낸다
4. `04-decisions.md` `## 4. 판정 로그`에 **`출처: 외부관찰`** 플래그를 달아 append
5. 구멍이 발견되면 `## 5. 신규 규칙 후보`에 별도 엔트리

> **원문 경고**(§1-10): **"그만큼 스트레스받을 수 있습니다. 세상에 이렇게 또라이가 많다니…"** / **"최신순으로 보기 지옥의 시작이거든요."** — 인용·반응 확인이 목적이므로 인기순으로 본다.

## 부록: 게이트 전이 사용 — 유튜브 밖으로

`05-provenance.md`의 `#전이가능프레임` 항목들은 콘텐츠가 아닌 대상에도 적용된다. 아래는 게이트를 다른 산출물에 대입한 형태.

### PB 브랜드 / 제품 기획
- G-1 → **"이 배합/제품을 왜 사야 하는데?"** / 이 제품이 소비자의 현실과 어떻게 맞닿아 있는가
- G-2 → 이 카테고리에 관심 없는 사람도 살 이유가 있는가 (§2-13 인사담당자 함정)
- G-4 → 이 제품의 **콘텐츠 각**은 무엇인가 (스펙 나열이 아니라 뾰족한 한 지점)
- G-6 → 사람들이 이걸 남에게 뭐라고 소개할 것인가
- G-7 → 소비자가 인지하지 못하는 원가는 쓰지 않는다 (§6-3의 "4K는 의미 없다"와 동일 구조)

### 랜딩페이지 / 세일즈 카피
- G-3 → 히어로 카피가 **반례**인가 **당위**인가
- G-4 → 스크롤이 달려가는 지점이 하나인가, 평평하게 나열되어 있는가
- G-8 → 실제 유입 환경(광고 클릭 직후, 모바일)에서 봤는가

### 조직 / 채용
- R-01 → 성과가 안 나왔을 때 **사람 탓으로 귀속하지 않는다.** 구조의 문제로 본다
- R-06 → 개인은 변주해야 하고 조직은 반복해야 한다. 지금 어느 쪽 문제인가
- §4-7 → 채용 순서: ① 내 시간을 세이브하는 사람 → ② 나보다 기술적으로 뛰어난 사람
