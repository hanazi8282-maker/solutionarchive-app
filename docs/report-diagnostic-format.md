# 진단형 운영 리포트 — 포맷 정의 & 예시

> **이게 이 앱의 핵심 산출물이다.** 데이터를 나열하지 않고 *문제 → 병목 → 개선안*을 서술한다.
> Claude Code는 이 문서를 **AI 인사이트 레이어의 출력 템플릿**으로 사용한다.
> `CLAUDE.md §3.1 / §3.4`, `PRD-phase1-sales-kpi.md §1.4·§2.4·§3` 연계.

---

## A. 철학 (왜 이렇게 만드나)

대부분의 대시보드는 "숫자를 보여주고 끝"이다. 사람이 그 숫자를 해석해야 인사이트가 나온다.
이 리포트는 그 해석 노동을 AI가 대신한다. 원칙 3가지:

1. **결론부터.** 맨 위에 "이번 주 가장 큰 문제 1개"를 박는다.
2. **인과로 설명.** 단일 지표가 아니라 *입력활동(전략맵) → 결과지표(KPI) → 성과(매출)* 의 사슬로 병목을 짚는다.
3. **행동으로 끝낸다.** 모든 진단은 담당자·기한이 붙은 액션으로 닫힌다. "그렇구나"로 끝나는 문장 금지.

---

## B. 리포트 구조 (5블록 고정)

1. **TL;DR (3줄)** — 종합 상태 + 최우선 병목 1개 + 이번 주 단 하나의 액션.
2. **스코어보드** — 전사 KPI 달성률, 브랜드별 매출·영업이익률, 적신호 개수. (여기만 '데이터')
3. **🚩 병목 진단** — 막힌 곳을 우선순위순으로. 각 항목은 반드시 인과 사슬 형태:
   `[막힌 입력]  →  [정체된 KPI]  →  [부진한 성과]` + 근거 수치.
4. **개선 방안** — 병목별 구체 액션 / 담당자 / 기대효과 / 난이도. 즉시 실행 가능 형태.
5. **다음 주 주목 지표** — 위 액션이 먹혔는지 판별할 선행지표(lead indicator).

---

## C. 병목 탐지 로직 (Claude Code 구현 지침)

**1단계 — 규칙 기반 후보 추출 (결정론적, 코드로):**
- KPI 달성률 < 70% 또는 `is_delayed = true`
- 영업이익률이 전주 대비 하락 또는 채널 평균 이하
- 전략맵 status가 N주 이상 `논의중`/`진행중` 정체 (활동 미가동)
- 콘텐츠 발행 목표 미달 (정량 KPI)
- 한 사람/한 브랜드에 KPI 과집중 (부하 불균형)

**2단계 — 인과 연결 (공통 키):**
- 연결 키 = `brand` + `channel_type`.
- 같은 brand+channel을 공유하는 [전략맵 활동] · [KPI] · [매출/광고 성과]를 한 묶음으로 본다.
- 예: `first_light + 페이드마케팅` 의 전략맵이 정체 → 같은 키의 매출 전환 저조 → 같은 키에 묶인 KPI 정체. 이 셋을 하나의 사슬로 출력.

**3단계 — AI 서술 생성 (Claude API):**
- 입력: 1~2단계 결과 + 원본 집계.
- 시스템 프롬프트 골격: *"너는 두더지웍스 운영 분석가다. 아래 데이터에서 가장 큰 병목을 인과 사슬로 짚고, 담당자별 즉시 실행 액션을 제시하라. 추측 수치 금지, 데이터에 있는 값만 사용. 어려운 마케팅 용어는 한 줄로 풀이."*
- 출력: B의 5블록 형식.

### 📋 두더지웍스 주간 운영 진단 — 2026.06.01~06.07

**TL;DR**
이번 주는 **퍼스트라이트 백화점 오픈(6/4, D-1)에 모든 리스크가 집중**돼 있다. 최우선 병목은 *오픈 광고 소재가 준혁의 인플루언서 군단 가동에 묶여 있다는 것* — 군단이 25%에 멈춰 UGC 소재 공급이 불확실하다. **이번 주 단 하나의 액션: 오픈용 광고 소재를 군단 의존에서 분리해 최소본을 오늘 확정.**

**스코어보드 (예시)**
- 전사 KPI 평균 달성률: 38% (예시) · 적신호 🚩 2건
- 브랜드별 KPI 부하: 퍼스트라이트 9건 / 리틀도르 3건 / 역전비결 3건 / 스인프 0건 ← **부하가 퍼라에 쏠림**
- 매출·영업이익률: (매출 연동 후 표시)

**🚩 병목 진단**

**1순위 — 백화점 오픈 광고 소재 공급 리스크 (시급)**
`[준혁: 인플루언서 군단 100명 운용 = 진행중 25%]` → `[태원: 6/4 오픈 광고 소재(UGC·준혁 시딩 의존) = 진행중]` → `[퍼라 백화점 오픈 성과]`
- 인과: 소재가 군단 UGC에 의존하는데 군단이 아직 25%. 오픈은 내일. 소재 공급 사슬이 가장 약한 고리.

**2순위 — 퍼라 대형C(박희선) 미가동 + 대형C 시스템 오너 중복**
`[박희선 = 논리구조 명확화 단계(계약 전)]` + `[대형C·시딩 시스템 구축이 태민·준혁 양쪽 KPI에 중복]`
- 인과: 대형C 매출 동력(박희선)이 아직 안 붙었는데, 시스템 구축 오너가 둘로 갈려 책임 소재가 흐림. 중복은 흔히 "둘 다 안 하는" 정체를 부른다.

**3순위 — 역전비결 콘텐츠 엔진 공백**
`[역전비결 콘텐츠 발행 KPI = 미설정]` 인데 `[남헌: 팬덤 프랜차이즈(UGC·시딩) = 진행중]`
- 인과: 팬덤을 돌리려는데 정작 주간 콘텐츠 발행 목표가 없다. 리틀도르(주30)·퍼라(주50)엔 있는 엔진이 역전비결엔 없음 → 팬덤 KPI의 연료 부재.

**개선 방안**

| 병목 | 액션 | 담당 | 기대효과 | 난이도 |
|---|---|---|---|---|
| 1 | 오픈 광고 소재 '군단 비의존' 최소본 오늘 확정(기존 소재+자체 촬영) | 태원 | 오픈 리스크 제거 | 중 |
| 1 | 군단 중 즉시 가능한 5~10명만 우선 UGC 요청(100명 완성 기다리지 말 것) | 준혁 | 소재 일부 즉시 확보 | 하 |
| 2 | 대형C 시스템 구축 단일 오너 지정(태민 or 준혁) | 태민·준혁 | 책임 명확화·정체 해소 | 하 |
| 2 | 박희선 계약 전환 데드라인 설정 | 태원 | 퍼라 대형C 동력 확보 | 중 |
| 3 | 역전비결 주간 콘텐츠 발행 KPI 신설(예: 주 20개) | 남헌 | 팬덤 KPI에 연료 공급 | 하 |

**다음 주 주목 지표 (선행)**
- 백화점 오픈 첫 3일 매출·전환 (1순위 액션 효과)
- 인플루언서 군단 가동 수 25% → ?% (소재 공급 회복 신호)
- 역전비결 콘텐츠 발행 수 0 → 신설 목표 대비
