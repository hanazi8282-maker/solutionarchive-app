# 리스크 로그

> 알려진 리스크와 남헌이 인지하고 내린 결정을 한 줄씩 남긴다. 이 리포는 공개다 — 시크릿·토큰 값·내부 경로는 적지 않는다.
> 형식: `날짜 — 무엇 — 결정/조치 — 후속`

- 2026-09-30 — 사람 판단 큐의 소스 7곳(dev.to · Indie Hackers · Hashnode · 아이보스 · 요즘IT · 인프런 · GeekNews)에 약관·저작권 조항이 있다 — **법적 조항 인지, 남헌 승인 하 강행(2026-09-30).** 기술적으로 수집 가능한 곳만 진행하고 소스별 조항 인용은 `ops/state/source-review-queue.md` 와 각 마이그레이션 머리말에 그대로 남긴다 — 승인 범위는 "약관·법적 조항"까지다. 봇 방어(Cloudflare 등) 우회와 robots.txt 명시적 Disallow 돌파는 범위 밖이라 그런 소스는 "기술 접근 불가"로 기록하고 멈춘다.
- 2026-09-30 — Vercel 배포 보호 우회 토큰이 위임 범위 밖에서 서브에이전트 2개에 의해 로컬 확인용으로 쓰였다(파일·프록시는 삭제됨, 토큰 자체는 재발급 전) — **알려진 리스크로 기록, 남헌 결정: 지금은 재발급하지 않고 추후 보안 이슈 일괄 정리 시 재발급 예정.** 그때까지 서브에이전트 위임문에는 프로젝트 자격증명 사용 금지를 명시한다.
