# Lutains — 조사 노트 (2026-11-07, 실패 사례 할당분)

## 결론 (3줄)
- 대상: Lutains (프랑스 2인 팀, 개발자+디자이너). 랜딩페이지 개선 AI 도구 → 사람이 하는 감사 서비스로 전환 → 2026-10-26 종료 선언. 큐 대상이 "미정"이라 웹서치로 직접 골랐다.
- 독자 문제 NO_FIRST_CUSTOMER / 병목 CONVERSION / 무브 3건, 전부 `outcome_direction=negative`.
- validate exit 0 (error 0, 경고 4: 수치·사실확인 등급 관련).

## 선정 이유
- 적립 목록에 없는 slug. 가장 가까운 기존 건(`blinkmetrics-...done-for-you-no-channel`, `olympia-ai-wrapper-moat-erosion-...`)과 겹치는지 확인: blinkmetrics 는 "통증 없는 대시보드", olympia 는 "AI 래퍼 해자 침식" 이고 이 건의 중심은 **돈 낼 손님으로 고른 집단이 직접 만들 수 있는 사람들**이라는 손님 선택 문제 — 다르다.
- 1인칭 출처가 연속 19편 공개돼 있어 사고의 흐름이 추적된다(아래).

## 사고의 흐름 (3.5번, 당사자 1인칭)
- 2025-12-10 글: 2년 넘게 만든 도구가 "AI 위에 얹은 껍데기"였다고 인정. 1차 런칭(2025-06) 1건 판매 후 0, 2차 런칭(2025-09) 방문 73·가입 10·판매 0.
- 2026-04-07 글: V3 로 Uneed 1위. 당일 투표 119·방문 68·가입 6·판매 0. 결론: 디자인만으로는 안 팔림, 3개월 검증 계획.
- 2026-05-18 글: 코딩을 멈추고 마케팅 14일(X 하루 답글 40개, 디렉토리 하루 2곳 등). 수치 결과 글에 없음.
- 2026-07 ~ 09 글: 도구 → 사람이 하는 감사 서비스로 전환, 브랜드 다시 만들기, "done-for-you" 쪽으로.
- 2026-10-18 글: 가격 $149→$99로 공개 인하, 몇 시간 뒤 첫 판매. 7일 신규 방문 119·전환 0.84%. 누적 "여름 3건 + 이번 1건".
- 2026-10-26 종료 글: 손님(인디해커)이 AI로 48시간 안에 직접 만든다 → "그래서 당신이 필요 없다". "몇 달 전부터 알았고 방향을 못 바꿨다". 영업(판매)을 건너뛰었다.

## 못 찾은 것 / 확인 불가
- 누적 매출액, 총 손실액(글은 "수천 유로"만), MRR: **확인 불가** (글에 없음).
- 2023년 시작 월: 확인 불가 (`period_start` 는 2023-01-01 로 둔 추정값 — 연도만 근거). 
- 2025-12-10·05-18·07~09 글은 요약 도구를 거쳐 읽었다. 숫자(1건 판매, 73 방문, 10 가입)는 무브 근거로 쓰지 않았다. 근거로 쓴 숫자는 04-07 글과 10-18 글, 10-26 글에서 다시 확인한 것(Uneed 수치, $149→$99, 119명, 0.84%, "3 sales this summer")뿐이다.
- 여름 3건이 감사 서비스 판매인지 SaaS 크레딧인지: 10-18 글 문맥상 감사 서비스로 읽혔으나 글 원문에서 직접 단정한 문장은 못 봤다 → 무브 claim 에는 "서비스로 바꾼 뒤 누적 4건"이라 적었다. 주의해서 읽을 것.
- 가격 인하의 인과: 판매 1건뿐이라 효과 판단 불가 — claim 에 그대로 적음.
- 현재 상태: 종료 글은 있으나 `lutains.com` 은 조회 시 감사 서비스 페이지가 그대로 열려 있고(가격 $99, 48시간) 종료 안내는 안 보였다. `outcome_status=shutdown` 은 창업자 선언 기준이며 사이트 폐쇄 확인은 아님.
- 독립 2차 출처: 없음. 근거가 전부 창업자 본인 블로그(자기보고)라 사실확인 등급이 C/D 에 머문다 — 정직한 결과.

## 어휘·제도 메모
- 6축/lever 는 어휘 안에서 골랐다. `reader_problem`: 가장 가까운 것은 NO_FIRST_CUSTOMER(첫 고객 문제). "손님을 잘못 골랐다"를 정확히 나타내는 코드는 어휘에 없다 — 어휘 갱신 후보 메모.
- pain-terms 규칙: move 0 claim 에 낱말이 없어 처음 error 였고 "유료"·"도입"을 문장에 넣어 해결.
- 이식성은 쓰지 않았다(사람이 승인 때 고름).

## VOC
- VOC 해당 없음. `ops/state/voc-inputs/index.md` 에 Lutains 프로젝트 없음. SaaS 창업가 페인 프로젝트(no_first_customer 등)는 HN 일반 댓글이라 Lutains 의 주장을 직접 받치지 않는다(AI 래퍼 글 1건은 다른 제품 이야기). `voc_inputs` 는 비웠다.

## 자가검증 (원칙 §0)
- 기획: 실패 사례, 손님 선택 문제를 중심 교훈으로.
- 개선: 처음엔 가격 인하를 독립 무브로 두려 했으나 n=1 이라 OFFER 무브에 합치고 "판단 불가"를 명시. 가격 효과를 긍정 교훈으로 돌리지 않았다.
- 남은 약점: 근거가 단일 출처(자기보고)라 발행 불가(사내 참고용)다.
