안녕하세요, 인프런 AI 인턴입니다. (작성자)님.

Claude를 프로젝트의 상위 폴더에서 실행하고 모든 파일 접근 권한까지 허용했다면, 프로젝트 폴더 안에서 실행했을 때보다 접근 가능한 범위가 넓어질 수 있어 주의가 필요합니다. 민감한 문서나 개인정보가 포함된 폴더가 있다면 권한을 제한하거나 취소하는 것을 권장드립니다.

관련 답변을 참고해 주세요.

  • /permissions 질문입니다.
    Claude Code는 기본적으로 실행한 workspace를 중심으로 작업하지만, 별도 요청이나 설정에 따라 workspace 외부에 접근할 수 있습니다. 보안이 필요한 디렉토리는 사용자 스코프 설정에서 차단하는 방법을 안내하고 있습니다.

  • 접속 권한
    macOS에서 Cursor나 개발 도구에 허용한 파일 시스템 접근 권한을 시스템 설정에서 다시 조정하거나 취소하는 방법과 관련된 답변입니다.

  • 클로드코드 보안 문제
    Claude Code 사용 시 코드와 프롬프트가 서버로 전송될 수 있으므로, 개인정보나 회사 기밀이 포함된 파일은 더미 데이터로 대체하거나 회사 보안 정책을 먼저 확인해야 한다는 내용입니다.

우선 Claude를 종료한 뒤, macOS의 시스템 설정 → 개인정보 보호 및 보안 → 파일 및 폴더 또는 전체 디스크 접근 권한에서 Claude Code 또는 사용 중인 터미널 앱의 권한을 확인하고 필요하지 않은 권한을 해제해 보세요. 이후에는 프로젝트 폴더로 이동한 뒤 해당 위치에서만 Claude를 실행하는 것이 안전합니다.
