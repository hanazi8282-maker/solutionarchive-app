### 정방향 (내 초안 검증)

`references/00-gate.md`의 4단계를 순서대로 실행한다. 매체별 게이트를 두 개 다 돌리지 않는다.

**Ⅰ. 공통 관문 3항목** — 매체 무관. 여기서 떨어지면 다른 검토 없이 반려한다.
  - U-1 타깃 (C-01) / U-2 구조 (C-12) / U-3 관찰 (C-08)
  - 이 셋은 솔파와 프드프가 완전히 일치한 항목이다. 가장 강한 규칙이다.

**Ⅱ. 조건 분기 5개** — D-1~D-5 표를 조회해 어느 쪽 규칙을 쓸지 결정한다.
  - Threads·릴스·숏폼 → 기본값 프드프
  - 유튜브 롱폼·브랜디드 → 기본값 솔파
  - 결정한 이유를 한 줄로 명시한다

**Ⅲ. 매체별 게이트** — 한쪽만 돈다.
  - 프드프면 `references/pdp-gate.md` G-0~G-13
  - 솔파면 `references/solfa-gate.md` G-0~G-10
  - ★ Ⅰ에서 이미 본 항목은 건너뛴다 (pdp G-3·G-7 / solfa G-2·G-4)

**Ⅳ. 충돌 3건** — X-1(감·재능) / X-2(알고리즘) / X-3(진위)를 만나면
  판정하고 **반드시 기록**한다. 이게 이 아카이브의 유일한 학습 입력이다.

**Ⅴ. 로그** — 출력 마지막에 판정 로그 엔트리를 복사 가능한 코드블록으로 제시한다.
  `출처`(자체발행/외부관찰), `방법론`(솔파/프드프/교차), **예측** 필수.

### 역방향 (남의 콘텐츠 분석)

★ 정방향과 결정적으로 다르다: **양쪽 게이트를 다 돌린다.**

1. Ⅰ의 3항목을 역방향으로 묻는다
2. 매체에 맞는 쪽의 G-R 질문표를 채운다 — 댓글·인용문 실물로. 추측으로 채우면 의미 없음을 알린다
3. **핵심 판정 2개**를 낸다:
   - 솔파 게이트로 탈락시켰겠는가?
   - 프드프 게이트로 탈락시켰겠는가?
4. 결과 처리:
   - 둘 다 통과 → 신뢰도 +1
   - 둘 다 탈락 → ★ 양쪽 공통 구멍. 최고 가치. 신규 규칙 후보
   - **한쪽만 탈락 → ★★ 조건부 규칙의 증거. cross-decisions.md 갱신 대상**

### 평가 모드

"몇 점", "평가 세트", "내 판정 실력"을 물으면 `eval-set.md`의 §2 문항만 제시하고
사용자 답변을 받은 뒤 §3으로 채점한다. §4 채점표의 규칙별 약점 진단까지 낸다.

### 공통 금지
- 게이트 항목을 건너뛰지 않는다
- 통과 여부를 애매하게 남기지 않는다 (통과/탈락/예외통과 셋 중 하나)

# ■ 프롬프트 B — Claude Cowork : 평가 세트 응시 (가장 먼저 할 것)

```

## 진행 방식
1. §3(정답)과 §4(채점표)는 절대 미리 보여주지 마. 내가 다 풀 때까지 가려줘.
2. §2의 Q1부터 순서대로, **한 번에 5문항씩** 제시해줘. 한꺼번에 30개 주면 집중이 안 돼.
3. 각 문항에 나는 [선택 + 근거(규칙명 또는 이유)]로 답할게.
4. 5문항 단위로 넘어갈 때 채점하지 말고 그냥 다음으로 가.
5. 30문항이 끝나면 그때 §3으로 일괄 채점해줘.

## 채점 규칙
- 각 문항 2점 (선택 1점 + 근거 1점)
- 근거는 표현이 달라도 **같은 규칙을 지목했으면 정답**
- ⚠️ **선택은 맞았는데 근거가 틀린 문항을 따로 표시해줘.** 우연히 맞힌 거라 재현이 안 돼

## 결과 리포트에 반드시 포함할 것
1. 총점 / 60 과 해석 등급
2. §4 채점표의 **규칙별 약점 진단** — 어느 규칙군에서 몇 개 틀렸는지
3. **C-01(타깃/표본)에서 2개 이상 틀렸는지** ← 가장 심각한 신호. 두 방법론이 완전히 일치한
   유일한 영역이라 여기서 틀리면 나머지가 무의미해
4. "선택 O / 근거 X" 문항 목록
5. 내가 약한 규칙 3개를 뽑고, 각각 어느 파일 어느 § 를 다시 읽어야 하는지

## 마지막에
약점 규칙 3개를 `pdp/04-decisions.md` 또는 `solfa/04-decisions.md`의
`## 5. 신규 규칙 후보`가 아니라 별도 메모로 정리해줘. 규칙 후보가 아니라 **내 학습 항목**이니까.
그리고 다음 역방향 세션에서 어떤 종류의 콘텐츠를 골라야 이 약점이 보완되는지도 알려줘.

# ■ 프롬프트 C — Claude Cowork : 역방향 세션 (통합 버전)

> 발행보다 **먼저** 돌린다. 프드프 권장 비율은 발행 1건당 역방향 5건 이상.

```
methodology/content/00-gate.md 의 Ⅵ(역방향 모드)로 아래 콘텐츠들을 분석해줘.

## 대상
[링크 또는 본문 5건]

## 매체
[Threads / 릴스 / 유튜브 롱폼 / 기타]

## 진행 방식

각 건에 대해:

**1단계 — 공통 관문 역방향 (Ⅰ)**
- U-1: 이 글은 어느 계층까지 닿았나? 그 분야 사람이 아닌데 반응한 사람이 있나?
- U-2: 어느 문단이 잘려 인용됐나 / 어디서 감정이 해소됐나?

**2단계 — 매체별 G-R 질문표**
- 숏폼·Threads면 `pdp/02-gate.md` G-R 질문표 (P-0~P-12 역방향)
- 롱폼이면 `solfa/02-gate.md` G-R 질문표 (R-0~R-9)
★ 댓글·인용문을 실제로 읽고 채워줘. 못 읽는 항목은 "확인 불가"로 남기고 추측으로 메우지 마.

**3단계 — 핵심 판정 2개 (여기가 제일 중요)**
```
□ 솔파 게이트로 이 글을 탈락시켰겠는가?  → 예/아니오 + 어느 항목에서
□ 프드프 게이트로 이 글을 탈락시켰겠는가? → 예/아니오 + 어느 항목에서
```

**4단계 — 결과 처리**
| 결과 | 처리 |
