# TweetFeast — 조사 노트 (2026-11-10, 실패 사례 할당분)

## 결론
- 대상: TweetFeast (트위터 데이터 CSV 내려받기 SaaS, 1인 파트타임, 2022-02 폐업). 이미 적립된 slug 와 겹치지 않음.
- 독자 문제: MAKE_BUT_NO_MONEY. 무브 3개 모두 `outcome_direction=negative`, 등급 D(수치 없음). 억지로 positive 로 돌리지 않았다.
- validate: error 0건, 통과(무브 3건·근거 6건). 경고는 수치 없음·published_at 2건뿐.

## 사고의 흐름 (1인칭 출처 확인됨)
- 출처: 창업자 블로그 사후 글(2022-02-05), Product Hunt 출시 댓글.
- 관찰: 출시 직후 트위터가 계정·API 를 영구 정지, 항소 무응답. 비슷한 CSV 도구들은 몇 해째 운영 중.
- 추론(창업자 본인의 추측): 차이는 출시글에서 'API 우회'로 소개한 문구일 것.
- 이 추론은 창업자의 추측이다. 트위터가 사유를 밝힌 곳은 찾지 못함 → 확인 불가.

## 못 찾은 것 / 확인 불가
- 출시 전 수요 확인을 했는지: 글에 언급 없음(했는지 안 했는지 확인 불가).
- 정지 시점: 블로그 요약은 출시 다음 날, 검색 요약은 출시 이틀 뒤로 엇갈림 → 정확한 시점 확인 불가.
- 트위터가 제시한 정지 사유, 경고·협의 이력: 확인 불가.
- 제작 시작 시점: 26주 서술과 2021년 5월 무렵 주간 진행 트윗(제품이 '감성 분석' 도구로 보임, 저장소 README 도 "sentiment analysis SaaS")이 맞지 않는다. 방향 전환이 있었는지·이유는 확인 불가라서 period_start 를 비웠다.
- 방문자 수·HN 순위·Product Hunt 득표(89 vs 99 로 도구 요약마다 다름)는 수치 근거로 쓰지 않았다. 수치는 모두 비움.
- 정지 후 수익이 났다는 검색 요약 한 줄은 원문을 못 열어 쓰지 않았다.
- polder 서브스택 Voiczy 글·Indie Hackers RecoverFlow 글은 403 으로 열지 못해 다른 후보로 갔다(우회 시도 안 함). Indie Hackers 게시본도 같은 이유로 본문 미확인.
- Content Goblin·Juttu 는 이미 적립된 slug 라 제외. 이 사례는 플랫폼 의존형 적립분(gummysearch 등)과 겹치는 면이 있으나, '출시글 문구 → 정지'와 '26주 선제작'이 새 축이다.

## 출처 구분
- 블로그·PH·README 는 모두 창업자 1인칭 = primary + 자기보고. 블로그와 IH 게시본은 같은 원 관측(`observation_key` 동일). 페이지는 모두 도구 요약으로 읽었고 원문 직접 대조는 못 했다.

## VOC
- VOC 해당 없음. 색인에서 트위터 데이터 내려받기 도구나 API 우회 도구와 맞는 프로젝트를 찾지 못했다(SaaS 창업가 페인 VOC 프로젝트는 시장 단위라 이 무브를 직접 받치는지 확인하지 못했다). `voc_inputs` 는 비워 뒀다.

## 자가검증 메모(원칙 §0)
- 개선점 1: 처음 초안의 move 0 claim 에 페인 낱말이 없어 validate 가 막음 → '유료 전환' 으로 고침.
- 개선점 2: 원인 단정 문장을 모두 '창업자 추측 / 확인 불가' 로 낮췄다. 검증 활동이 없었다는 것도 '글에 없다' 까지만 썼다.
- 이식성(transferability)은 쓰지 않았다(사람이 승인 때 고른다).
