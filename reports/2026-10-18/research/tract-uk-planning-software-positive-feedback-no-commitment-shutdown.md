- "영국 인허가·토지 중개 시장이 벤처 모델에 안 맞는다", "미국으로 갈 걸" 같은 시장 진단은 영국 인허가라는 한정된 전제라 무브로 쓰지 않았다.
- 사무실·브랜딩·미국 출장·계약직·불필요한 채용에 쓴 돈(창업자가 "가장 화가 난다"고 쓴 항목)은 투자를 받은 팀 전제라 1인 독자에게 옮기기 어려워 무브에서 뺐다. 요약에만 언급.
- 공동창업자 기술이 겹친 문제도 뺐다(독자가 혼자인 경우가 많다).

## 못 찾은 것 / 확인 불가
- 포스트모템 본문의 게시일: 확인 불가. BusinessCloud 기사 2025-04-04 에 "released" 로 나오고 폐업 공지는 X 2025-04-03 이라 이 무렵이지만, 본문 자체의 날짜는 페이지에 없어 evidence.published_at 을 null 로 뒀다.
- Scout 방문자 수: WebFetch 요약에는 "수백 명"이 나왔으나 원문 그대로 인용을 받지 못해 수치로 쓰지 않았다. Landstack 의 API 차단·Lite 출시(2025-02)·"개발자 일주일"도 요약 기반이라 원문 문장 인용 없이 서술로만 두었다(claim 에 쓴 내용은 원문 페이지 재확인 권장).
- 매출 0 이라는 수치는 자기보고 한 건뿐이다. 투자자 쪽(Ada Ventures·Concept Ventures) 별도 발언은 BusinessCloud 로만 확인했고 독립 출처로 세지 않았다(같은 원 관측).
- 현재 상태: 폐업 후 자본 반환(포스트모템 자기보고). 이후 활동은 확인 불가 → outcome_status=shutdown 은 자기보고 근거.
- 비교 대상 Landstack Lite 가 실제로 Scout 에 반응한 것인지는 창업자 추측("potentially reactive")이라 claim 에 인과로 쓰지 않았다.
- 매출 0→0 지표는 변화가 없는 지표다. 숫자 변화가 아닌 "0 이 유지됨"을 근거로 쓴 것이니 승인할 때 지표로 적절한지 봐 달라.
