# 교차 판정 (Cross Decisions) — 솔파 × 프드프

> **성격**: 두 방법론이 **같은 질문에 어떤 답을 하는가**를 충돌시킨 문서. append-only.
> **위치**: `methodology/content/cross-decisions.md` (두 폴더의 상위)
> **참조**: `solfa/04-decisions.md`(R-01~R-14) / `pdp/04-decisions.md`(P-01~P-14)

---

## 0. 이 파일이 존재하는 이유

솔파 SEED(R-xx)와 프드프 SEED(P-xx)는 각각 **한 사람(혹은 한 팀)의 판단**이다. 그것이 틀렸는지 확인하는 경로는 지금까지 두 가지뿐이었다.

1. **내가 직접 발행하고 실패한다** — 느리다(D+30에 1건)
2. **남의 터진 글을 역방향으로 관찰한다** — 간접적이다

세 번째 경로가 이 파일이다.

```
solfa/04-decisions.md    R-01 ~ R-14   (유튜브 롱폼 / 개인 제작자 / 감상 중심)
pdp/04-decisions.md      P-01 ~ P-14   (인스타 릴스 / 마케팅 조직 / 전환 중심)
         ↓  같은 질문에 다른 답을 하는 지점을 찾는다
cross-decisions.md       C-01 ~ C-nn
```

### 산출물 3분류

| 결과 | 의미 | 처리 |
|---|---|---|
| **같은 답** | ★ **도메인 불변 원리.** 매체·목적·시대가 달라도 통했다 | 신뢰도 최상. 가장 먼저 적용 |
| **다른 답** | ★★ **조건부 규칙이라는 강한 증거.** "어떤 조건에서 갈리는가"가 새 규칙 | 조건을 찾아 확정하면 `신규 규칙`으로 승격 |
| **한쪽만 존재** | 그 방법론의 **고유 자산**. 다른 쪽의 결손일 수도 있다 | 전이 가능성 별도 판정 |

**핵심**: 두 전문가가 갈리는 지점은 이미 **"조건에 따라 달라지는 문제"**라는 강한 증거다. 그러므로 이 파일은 **내가 실패하지 않고도 조건부 규칙을 발견**하는 장치다.

### 두 원문의 좌표 차이 (해석의 전제)

| 축 | 솔파 (윤성원) | 프드프 (자청·이상한마케팅) |
|---|---|---|
| **매체** | 유튜브 롱폼(7~10분) | 인스타 릴스(3초~1분) |
| **목적** | 감상(C)의 전달, 팔로워십 | 반응률 → 전환·매출 |
| **주체** | 개인 제작자 → 소규모 조직 | 마케팅 대행 조직 |
| **수익 모델** | 브랜디드 콘텐츠 | 상품·서비스 판매, 강의 |
| **시청 태도 가정** | 뒤로가기가 자유로운 수동적 시청 | 1초 스크롤, 저장·공유 행위 |
| **성공 정의** | 100만~800만 뷰 + 채널 팔로워십 | 100만 조회수 + 구매 전환 |

> 이 차이 때문에 갈리는 것인지, 원리 자체가 다른 것인지를 매 항목에서 구분해야 한다.

## 1. C-01. 타깃 범위 — **같은 답 ★**

| | 진술 |
|---|---|
| **솔파 R-11** | **"'여러분의 타깃층을 찾아라'가 아니라, '넓히는 것'"** / 인사담당자 함정 / 호박벌 870만 |
| **프드프 P-03(X)** | 표본 이론. **"모든 콘텐츠와 모든 사업 아이디어는 표본이 넓어야 된다"** / 김경일 교수 편 1만 → 110만 |

**교차 판정: 완전 일치**

두 원문이 **독립적으로 같은 결론에 도달**했고, 실패 사례의 형태까지 같다.

| | 솔파의 실패 사례 | 프드프의 실패 사례 |
|---|---|---|
| 형태 | **"'난 인사담당자야' 하면서 막… '꿀팁!'"** — 그 직군만 볼 수 있게 만듦 | **"사이코패스를 찾는 5권의 책"** / **"프롬프트 잘하는 법"** — 그 관심층만 볼 수 있게 만듦 |
| 진단 | **"심지어 여러분들이 인사담당자 그 직군에 있어도 (…) 아마 안 볼 거예요."** | **"이거는 아무리 잘 만들어도 100만 조회수를 갈 수가 없는 거야."** |
| 해법 | 계층 변화 / 역할 반전 / 대상 교체 / 관계 도입 | 표본을 넓히는 카피로 치환 |

**공통 판별 질문**
- 솔파: **"이 분야에 관심 없는 사람도 볼 이유가 있는가?"**
- 프드프: **"5천만 명 중 몇 명이 이 주제에 관심이 있는가?"**

**둘 다 인정하는 예외도 같다**
- 솔파: 소재가 마이너한 것은 괜찮다(호박벌 870만)
- 프드프: 이미지형 계정은 표본 계산이 불필요 / 좁은 표본도 매출은 가능(§12-1)

**결론**: ★★★ **도메인 불변 원리.** 매체·목적·시대가 전부 다른데 같은 답이 나왔다. **가장 먼저 적용해야 할 규칙이며, 이걸 어기는 초안은 다른 검토 없이 반려해도 된다.**

**Threads 적용**: 첫 문장은 무조건 넓힌다. 니치한 주제여도 그 업계 사람만 이해하는 문장으로 시작하지 않는다.

`교차상태: 정합` `신뢰도: 최상` `확정`

## 2. C-02. 감 · 재능 — **정면 충돌 ★★ 가장 큰 것**

| | 진술 |
|---|---|
| **솔파 R-12** | **"평생을 노력해도 이미 어릴 때부터 쌓아온 이 감을 이기기는 어렵다"** / 솔파 §10-7 제작자 양성 실패 — **"전 실패했다고 생각합니다."** / **"웹 컨텐츠 성공 필살기 → 없어."** |
| **프드프 §3-1** | **"좀 과장하면 일주일만 오늘 시키는 트레이닝대로만 하면 진짜 일반인도 웬만한 인플루언서보다 더 높은 혜안. 그들은 감각으로만 한다면 우리는 14가지의 공식을 토대로 초고수가 될 수밖에 없어요."** |

**교차 판정: 정면 충돌**

같은 대상(감·재능)에 대해 **정반대 결론**이다. 그런데 자세히 보면 두 진술의 **측정 대상이 다르다.**

| | 솔파가 말하는 것 | 프드프가 말하는 것 |
|---|---|---|
| 대상 | **격차의 절대적 크기** | **공식 적용의 성과** |
| 비교군 | 감이 좋은 사람 vs 나 | 공식 없는 나 vs 공식 있는 나 |
| 성공 정의 | 800만 뷰 / 골드버튼 2개 / 시리즈물 지속 | 100만 조회수 1건 / 전환 발생 |
| 실증 | 기획안을 줘도 다음부터 못 함(솔파 §10-7) | 수강생 109건 100만 달성 |

**갈리는 조건 — 이 문서의 판정**

1. **재현성의 층위가 다르다.** 솔파의 실패담은 **"시리즈물로 해. 못 해."** — 즉 **반복 재현**의 실패다. 프드프의 성공담은 **단발 100만**이다. 두 진술은 서로 반증하지 않는다.
2. **매체가 다르다.** 릴스는 형식 변수가 적어(1초 후킹·카피·음원·박자) 공식화가 가능하다. 롱폼은 7~10분의 구성·감정 곡선·인물 연출까지 변수가 커서 공식화가 어렵다.
3. **솔파도 격차 축소는 가능하다고 본다**: **"저희의 목표는 이걸 최대한 빨리 줄이는 거죠. 싱크 최대한 빨리 맞추고."** / **"우리는 '실패하지 않는 법에 대해서 배우겠다'입니다."**

**조건부 규칙 초안**

```
변수가 적고 형식이 정형화된 매체(숏폼·카피·썸네일)  → 공식으로 상위권 진입 가능 (프드프)
변수가 많고 구성이 긴 매체(롱폼·서사·인물 연출)      → 공식은 재앙 회피까지. 최상위는 감 (솔파)
그리고 어느 쪽이든, 반복 재현은 공식만으로 안 된다 (양쪽 공통)
```

**⚠️ 검증 필요**: 위 조건은 이 문서의 추론이다. 실측으로 확인해야 한다.
- 검증 방법: **같은 사람이 릴스 공식으로 10건, 롱폼으로 10건**을 만들어 상위 편차를 비교한다.

`교차상태: 충돌` `조건 초안 있음` `검증대기`

## 3. C-03. 초반 몇 초 — **충돌 (조건 명확)**

| | 진술 |
|---|---|
| **솔파 §1-12** | **"뭐 3.5초면 어떻고 4초면 어떻고 9분이면 어떻고 11분이면 어떻습니까. 영상만 잘 만들면 되지."** / 3초 룰의 **기원**은 설명하되 규칙 자체는 상대화 |
| **프드프 §3-8** | **"1초만에 인식이 되지 않으면 사람들은 릴스를 넘겨버리겠죠."** / **"릴스를 만들 때 항상 이 도입부에 사람들을 어떻게 멈추게 할까 가장 오래 고민을 하셔야 돼요."** |

**교차 판정: 충돌하되 조건이 명확하다**

솔파의 진술은 **"규칙을 외우지 말고 왜 그런 규칙이 생겼는지를 알라"**는 맥락에서 나온다 — **"어떤 규칙이 있는가를 외우려고 하기보다는 왜 그런 규칙이 생겼는지를 아는 게 중요하다고 생각을 하고 저는 그게 콘텐츠와 플랫폼의 관계 때문이라고 생각해요."**

**즉 솔파는 3초 룰을 부정하는 게 아니라 그것의 상위 원리(플랫폼 소비 태도)를 보라고 한다.** 프드프의 1초 법칙은 그 원리를 릴스라는 특정 조건에 적용한 결과값이다.

| 조건 | 답 |
|---|---|
| **소비 환경이 스크롤 피드** (릴스·쇼츠·틱톡·Threads) | **1~3초 절대.** 프드프 적용 |
| **소비 환경이 클릭 후 진입** (유튜브 롱폼·블로그·뉴스레터) | 썸네일·제목이 그 역할을 이미 했으므로 도입부 몇 초는 유연. 솔파 적용 |
| **어느 쪽이든** | 규칙보다 **소비 태도**를 먼저 측정한다(솔파 §11-1의 판별 질문 6개) |

**결론**: 표면적 충돌, **실질은 조건부 규칙.** 솔파의 상위 원리 + 프드프의 하위 적용값으로 봉합된다.

**Threads 적용**: Threads는 스크롤 피드다. → **프드프 적용. 첫 문장에 가장 오래 고민한다.**

`교차상태: 조건부` `확정`

## 4. C-04. 알고리즘 — **어긋남 (양쪽 다 검증 필요)**

| | 진술 |
|---|---|
| **솔파 §1-13** | **"최적화 이런 거 없습니다."** / 태그를 아예 안 검 / **"유튜브 신이 나타나서 (…) 천만 명에게 강제로 시청하게 하겠다. 근데 중요한 건 그다음엔 어떡할 거냐"** |
| **프드프 §1-1, §1-10** | **"이 반응률이라는 한 가지 원리만 이해를 하고 계시면"** + **"하루에 딱 1~2분만 (…) 좋아요를 눌러주고 댓글을 (…) 특히 영상을 업로드한 직후에"** |

**교차 판정: 어긋남**

- **솔파**: 알고리즘을 **사고 대상에서 제외**한다. 좋은 콘텐츠면 뚫린다(칠성 레이블 2년 후 뚫림).
- **프드프**: 알고리즘을 **조작 가능한 변수**로 본다. 반응률 설계 + 학습 작업.

**그런데 두 진술의 핵심 주장은 사실 같다**

| | 솔파 | 프드프 |
|---|---|---|
| 결론 | **"결국 공유할 만한 컨텐츠를 만들면 뚫릴 수밖에 없다"** | **"콘텐츠 퀄리티만 좋다면 탄생을 할 수밖에 없는 구조"** |

**갈리는 것은 "그 위에 조작을 얹을 것인가"뿐이다.**

- 솔파: 얹지 않는다 (태그도 안 검)
- 프드프: 얹는다 (알고리즘 학습 작업, 해시태그는 "힌트 정도")
- ⚠️ 프드프 내부에서도 P-13으로 충돌한다.

**조건부 규칙 초안**
```
콘텐츠 품질이 전제 조건이라는 것 = 양쪽 합의 → 불변 원리
그 위의 조작 작업 = 프드프도 내부 충돌(P-13) → 판정 보류. 실측으로 결정
```

**실측 설계**: 같은 품질의 글 10건을 5건은 업로드 직후 관련 계정에 반응 작업, 5건은 아무것도 안 함 → 초기 도달 비교.

`교차상태: 부분 정합 + 판정 보류` `실측 설계 필요`

## 5. C-05. 레퍼런스 출처 — **다른 답 = 조건부 규칙 ★**

| | 진술 |
|---|---|
| **솔파 §8-6, §8-7** | **레퍼런스는 다른 매체에서** — 영화, vimeo, 황금종려상. 유튜브 안에서 찾으면 이미 소모된 것 |
| **프드프 §7-1** | **"반드시 나와 같은 분야에서 잘 터진 영상들을 먼저 분석을 해보셔야 해요. 이게 너무너무 중요합니다."** |

**교차 판정: 정면으로 다른 답 → 조건이 새 규칙이다**

**갈리는 조건 — 두 원문 안에 답이 이미 있다**

| 조건 | 답 | 근거 |
|---|---|---|
| **기본기 미완성 단계** | **같은 분야·같은 플랫폼 (프드프)** | 프드프 §2-1 피카소 이론 — 기본기를 다 한 다음에 창의성 / 프드프 §7-1의 좌절 경험 — **"성공한 콘텐츠를 분석해주는 건 좋은데 내 업종에 어떻게 적용하지?"** |
| **기본기 완성 후 차별화 단계** | **다른 매체 (솔파)** | 솔파 §8-5 조립은 창작 / 프드프도 인정 — **"처음에는 레퍼런스를 적용해서 만들다가 점점 이렇게 나만의 색을 찾아갈 수 있는 거죠."**(§11-1) |
| **형식이 이미 포화된 카테고리** | **다른 매체** | 솔파 §8-8 요소 중첩 판정 |
| **형식이 아직 없는 신규 카테고리** | **같은 분야 (없으면 인접 분야)** | 프드프 §12-1 — 누수탐지 → 인테리어·청소로 확장 |

**두 원문이 실제로 만나는 지점**
- 프드프도 **해외 레퍼런스**를 적극 권한다(§7-2) — **"해외 같은 경우에는 모수가 되게 넓다 보니까"**. 이것은 솔파의 "다른 매체"와 구조적으로 같다: **아직 이 시장에서 소모되지 않은 형식을 가져온다.**
- 프드프 §11-1의 오컬트 시도(해골·왕좌의 게임)는 책 카테고리 밖에서 온 것이다.

**★ 조건부 규칙(확정 후보)**
```
레퍼런스의 원칙: "아직 이 시장에서 소모되지 않은 형식"을 가져온다.
  → 초보: 내 분야 안에서도 아직 안 쓴 것이 많다 → 같은 분야부터 (프드프)
  → 숙련: 내 분야는 이미 다 봤다 → 해외 / 다른 매체 / 다른 장르 (솔파 + 프드프 해외편)
두 방법론은 같은 원칙의 서로 다른 단계를 말하고 있다.
```

**결론**: ★★ **이것이 이 교차 검증의 첫 산출물이다.** 두 원문 중 어느 쪽도 이 통합 원칙을 명시하지 않았다.

`교차상태: 조건부 → 통합 원칙 도출` `확정` `→ 신규 규칙 후보 N-CROSS-01`

## 6. C-06. 연출 vs 주작 — **정면 충돌 ★★**

| | 진술 |
|---|---|
| **솔파 R-14** | **"이 사람이 느끼지 않는 감정에 대해서는 말하지 않게 하는 거 같아요."** / 사전 동의 / **"이들이 오히려 본인을 숨기고 있다면 그걸 꺼내 줘야죠. 전 그게 연출의 역할"** |
| **프드프 P-14** | **"제 최애 맛집 공개합니다"** — 가게가 직접 만들고 손님 시점으로 씀. **"전혀 상업적으로 느껴지지가 않죠."**(성과로 제시) |

**교차 판정: 정면 충돌**

| | 솔파 | 프드프 |
|---|---|---|
| 허용 | 시점 재조정 / 상황 설계 / 이미지 캐스팅 | 시점 위장 / 후기성 프레이밍 / 간접 가치 전달 |
| 금지 | **느끼지 않은 감정을 말하게 하기** | (명시적 금지선 없음) |
| 자기 검열 | **"어, 이거 사기 아니냐?"**(솔파 §7-11) | 없음 |
| 안전장치 | 사전 동의 공지 | 캡션에 출처 표기 권고(수준: "~하면 더 확실하고 좋겠죠") |

**갈리는 조건 — 이 문서의 판정**

두 방법론은 **"누가 화자인가"**에서 갈린다.

| | 솔파 | 프드프 |
|---|---|---|
| 화자 | **출연자(타인)** — 그 사람의 감정을 대신 말하게 하는 문제 | **광고주 자신** — 자기 상품을 남의 시점으로 말하는 문제 |
| 위험 | 타인의 인격·감정에 대한 침해 | 소비자 기만 / 표시광고법 |
| 성격 | **윤리적 문제** | **법적·신뢰 문제** |

**즉 다른 종류의 위험을 다루고 있어서 기준이 다른 것이다. 둘 다 필요하다.**

**★ 통합 판정선 초안**
```
① 타인이 등장하면 → 솔파 R-14 적용 (감정의 진위 + 사전 동의). 프드프에 이 축이 없다
② 내가 광고 주체이면 → 프드프 P-14 + 출처 표기 강화. 솔파에 이 축이 없다
③ 둘 다 걸리면 → 더 엄격한 쪽을 적용한다
④ 공통 최저선: 사실(숫자·이력·후기)은 실제여야 한다
```

**⚠️ Threads 적용 시 주의**: 1인칭 경험담이 주력이면 ②가 상시 발동한다. **"내가 광고 주체인 글"과 "순수 경험담"을 스스로 구분해 로그에 남긴다.**

`교차상태: 충돌 → 상보 관계로 재해석` `통합 판정선 초안` `검증대기`

## 7. C-07. 현실 연결 — **같은 자리, 다른 구조화**

| | 진술 |
|---|---|
| **솔파 §2-10** | **"이 아이디어가 나오기 전에 어떤 현실이 있는가를 봐야 합니다."** / **"이 영상의 행위가 우리의 일상과 닿아있다"** |
| **프드프 §5-1** | **생존과 번식** → **돈 · 건강 · 인간관계** 3분류 + **하위 욕망 배제**(§5-2) |

**교차 판정: 같은 자리를 차지하되 구조화 방식이 다르다**

| | 솔파 | 프드프 |
|---|---|---|
| 형태 | **서술적** — 개별 기획마다 "어떤 현실인가"를 문장으로 쓴다 | **분류적** — 3개 카테고리 중 어디에 걸리는지 판정한다 |
| 장점 | 새로운 현실을 발견할 수 있다 | 빠르고 판정이 명확하다 |
| 단점 | 판정이 주관적이고 느리다 | 3분류 밖의 동기를 놓친다 |
| 실패 진단 | **"아이들이 사랑에 대해서 색다른 감정을 아무리 전달해준다고 한들 우리의 인식과 크게 영향은 없죠."** | **"효도는 하위 욕망이에요."** |

**두 실패 진단이 구조적으로 동일하다.** 솔파의 "우리 인식에 영향 없음"과 프드프의 "하위 욕망"은 같은 것을 다르게 부른다.

**★ 통합 절차 초안 (양쪽의 장점 결합)**
```
1단계 (프드프): 돈 / 건강 / 인간관계 중 어디에 걸리는가? → 걸리지 않으면 하위 욕망일 가능성 높음
2단계 (솔파):   그 욕구가 "이 아이디어가 나오기 전에 이미 있던 현실"인가? → 사후 정당화 차단
3단계 (프드프): 표면 주제가 아니라 근원 이득까지 내려갔는가? (§5-5 살림 → 돈)
```

**결론**: 상보적. 프드프로 빠르게 걸러내고 솔파로 사후 정당화를 차단한다.

`교차상태: 상보` `통합 절차 초안` `확정`

## 8. C-08. 관찰 · 분석 — **같은 답 ★**

| | 진술 |
|---|---|
| **솔파 §12-4, §1-10, §2-15** | **"결과적으로 느는 건 디테일을 캐치하는 능력"** / **"저는 진짜 몇천 개 읽어요."** / **"감이라는 건 (…) 상호작용의 관찰이 누적된 거"** |
| **프드프 §3-2, §7-1** | **"강의에서 얻어 가야 하는 게 딱 한 가지 있다면 그건 바로 이 분석하는 습관입니다."** |

**교차 판정: 완전 일치**

- 솔파의 최대 덕목 = **관찰**
- 프드프의 유일한 필수 습관 = **분석**
- 둘 다 **"이것만 하면 나머지는 자동으로 따라온다"**고 말한다.
  - 솔파: **"감은 마법이 아닙니다. 일상에서 무의식적으로 축적된 '데이터의 합'입니다."**
  - 프드프: **"다른 것들은 솔직히 말씀드리면 이 분석을 계속하다 보면 자연적으로 깨닫게 되는 부분이기도 합니다."**
- 무의식화 시점까지 같다.
  - 솔파: **"이런 상호작용의 관찰이 누적된 거거든요."**
  - 프드프: **"그다음부터 안 하셔도 그냥 콘텐츠 보면서 자동으로 분석이 되시거든요."** / **"이게 한번 머리에 달라붙으면 그다음부터 세상이 바뀌게 돼요."**

**갈리는 것은 대상뿐**
- 솔파: 반응(댓글)을 읽는다 + 현상의 디테일을 본다(육아 프로, 릴스, 전참시)
- 프드프: 성공한 콘텐츠의 구조를 해체한다

**결론**: ★★★ **도메인 불변 원리.** 그리고 이것이 `02-gate.md`의 **G-R(역방향 모드)**가 두 아카이브 모두에서 최우선 실행 항목인 이유다.

`교차상태: 정합` `신뢰도: 최상` `확정`

## 9. C-09. 하방선 설계 — **솔파 고유 자산 / 프드프 결손**

| | 진술 |
|---|---|
| **솔파 R-08** | **"'이거 안 되면 어떡함?' 까지만 해놓으면 사실 끝나는 거."** / 12씬 그물 / **"'제발!!!!' 이러면서 주사위를 던져 (…) 이러면 좋은 연출자가 아니다."** |
| **프드프** | **대응 개념이 없다.** |

**교차 판정: 한쪽만 존재 → 전이 가능성 판정**

프드프에는 **"이 영상이 안 터지면 어떻게 되는가"**에 대한 사전 설계가 없다. 대신 다른 방식으로 대응한다.

| | 프드프의 대응 방식 |
|---|---|
| **양으로 커버** | **"조회수 2,3000 정도만 나와도 되니까 (…) 일단 시작하는 게 중요합니다."** |
| **비용 최소화** | 템플릿 1분 제작 — 실패해도 손실이 작다 |
| **좁은 표본 전략** | 5천 조회수로도 매출(§12-1) |

**즉 프드프는 하방을 "설계"하지 않고 "낮은 비용"으로 처리한다.** 그런데 이것은 기획형 릴스(§6-6, 프리미어 편집·나레이션 녹음)에는 적용되지 않는다. **공수가 큰 콘텐츠에 대한 하방선이 프드프에 결손되어 있다.**

**★ 전이 판정: 전이 가능. 전이 권장.**
```
프드프 기획형 릴스(공수 大)에 솔파 R-08을 이식한다:
  "이 영상이 조회수 5천이어도 남는 게 무엇인가?"
  → 촬영 소재 재활용 / 캡션 자산 / 반박 제거 리스트업 / 고객 인터뷰 원본
그리고 그것이 확보되면 나머지는 상방으로 둔다.
```

**Threads 적용**: 공들인 글일수록 "반응 0이어도 남는 것"을 먼저 정한다.

`교차상태: 고유자산(솔파) → 전이 권장` `확정`

## 10. C-10. 효율화 — **같은 답**

| | 진술 |
|---|---|
| **솔파 R-13** | **"내가 만드는 시간과 사람들이 소비하는 시간의 밸런스"** / 기준: **"독자가 그 차이를 인지하는가"** / **"이거 할 바에 나는 딸깍 쇼를 하겠습니다."** |
| **프드프 P-08, §10-1** | **"저는 극한으로 효율을 중요시 여기는 사람이에요."** / 제작 시간 1분·10분·30분 / **"염라대왕이 와가지고 너 1분 만에 릴스 못 올리면 너는 사형이야라고 하면은 저는 1분 만에 이 영상을 올릴 수가 있어요."** |

**교차 판정: 일치**

- 솔파: 7만원 제작비가 200만원보다 조회수가 잘 나온다 — **"보는 사람들은 잘 몰라."**
- 프드프: 미적 감각 없이 쿠팡 3만원 셔츠로 3분 촬영 + 3분 편집 = 60만

**단, 판정 기준이 다르다**

| | 기준 |
|---|---|
| **솔파** | **"독자가 그 차이를 인지하는가"** — 인지하면 무제한 투입(BGM 하루 종일, 인터뷰 500분) |
| **프드프** | **"목적이 조회수인가 전환인가"** — 조회수면 투입, 전환이면 최소(P-08) |

**★ 통합 판정선**
```
1차 (솔파): 독자가 이 차이를 인지하는가? → 인지 못 하면 즉시 중단
2차 (프드프): 인지한다면, 목적이 도달인가 전환인가? → 전환이면 그래도 최소화
```
- 솔파 기준만 쓰면 도달 지향으로 과투입할 수 있고, 프드프 기준만 쓰면 인지되는 요소를 놓칠 수 있다.

`교차상태: 정합 → 통합 판정선` `확정`

## 11. C-11. A에 맥락·권위 부여 — **같은 방향, 다른 어휘**

| | 진술 |
|---|---|
| **솔파 §2-2** | **"우리는 그 사람을 소비하는 게 아니라 그 사람이 놓인 어떤 상황과 어떤 맥락을 소비하는 거거든요."** / 제아를 **"아브라카다브라를 모르는 상대 앞에 놓인 40살쯤 된 여성"**으로 재정의 |
| **프드프 §4-8** | **권위 부여** — **"13년 차 피부과 전문의"**, **"시간당 90만 원 상담사"**, **"연세대"** |

**교차 판정: 같은 조작, 다른 목적**

두 방법론 모두 **A(화자·출연자)에 라벨을 붙여 재정의**한다. 그런데 목적이 다르다.

| | 솔파 | 프드프 |
|---|---|---|
| 붙이는 라벨 | **계층·상황** ("저 계층, 저 상황에 놓인 저 사람은 어떤 사람일까") | **권위·전문성** ("이 사람 말은 믿어도 된다") |
| 목적 | **감정 이입** | **반박 차단** |
| 원문 | **"제가 '저 윤성원이에요' 이러면 누가 절 보겠어요."** | **"이 약사 가운을 입은 사람이 (…) 사람들은 반박을 할 여지가 없어요."** |

**둘 다 "그냥 나"로는 아무도 안 본다는 진단에서 출발한다.**

**★ 통합**: 라벨은 **두 종류를 다 붙일 수 있다.**
```
권위 라벨 (프드프): 신뢰를 만든다 → 정보형 콘텐츠에 필수
계층·상황 라벨 (솔파): 이입을 만든다 → 서사형 콘텐츠에 필수
둘 다 붙이면: "13년차 피부과 전문의인데 정작 내 피부는 망가져 있었다" (권위 + 상황)
```
- 프드프의 **언매칭**(§3-13)이 사실 이 결합의 한 형태다: **"나는 서울대지만 평생 책 한 권도 읽지 않는다"** = 권위 라벨 + 상반된 상황.

`교차상태: 상보 → 결합 가능` `확정`

## 12. C-12. 스토리텔링 — **같은 답**

| | 진술 |
|---|---|
| **솔파** | 기획안 전반에 서사 구조. §3-9 콘텐츠 각(달려가는 장면) / §5-1 강산에 편 우회 질문 |
| **프드프 §3-10** | **"'내가 안 좋았던 상황', 그리고 '그 상황을 해소하는 과정', 그리고 '해소된 후' (…) 그게 없으면 스토리텔링이 아닌 겁니다."** |

**교차 판정: 일치. 다만 프드프가 더 형식화되어 있다.**

- 솔파의 **"달려가는 장면"**(§3-9) ≈ 프드프의 **"해소되는 구간"**
  - 솔파: **"실제 영상은 10분이고 술 취한 사람이 나오는 건 한 30초 정도밖에 안 되지만"** — 나머지는 그 30초를 위해 존재
  - 프드프: **"여기서 보면서 느꼈던 감정이 딱 해소가 되는 구간이 있으면 터진 거예요."**(청담 스테이크 "7만 6천원")
- **★ 이것은 같은 개념이다.** 솔파는 "콘텐츠 각", 프드프는 "해소 구간"이라 부른다.

**통합 판별 질문**
```
이 콘텐츠에서 "달려가는 지점 = 해소되는 구간"이 어디인가?
→ 하나로 특정되지 않으면 평평한 나열이다 (양쪽 공통 진단)
```

`교차상태: 정합 → 용어 통합` `확정`

## 14. 이 파일의 사용법

### 14-1. 초안을 쓸 때

**불변 원리 3개를 먼저 통과시킨다.** 여기서 떨어지면 나머지는 볼 필요가 없다.
1. **C-01** — 이 분야에 관심 없는 사람도 볼 이유가 있는가
2. **C-12** — 달려가는 지점 = 해소 구간이 하나로 특정되는가
3. (C-08은 상시 습관이므로 초안 단계 항목이 아님)

### 14-2. 두 방법론이 다른 답을 낼 때

**조건부 규칙 5개를 조건표로 조회한다.** 조건이 명확하면 그대로 적용하고, 애매하면 로그를 남긴다.

### 14-3. 미해결 충돌 3개를 만났을 때

**반드시 로그를 남긴다.** 이것이 이 아카이브에서 가장 값진 데이터다.
- 어느 쪽을 택했는지
- 왜 그렇게 판단했는지
- 예측(이 판정이 맞다면 어떤 결과가 나와야 하는가)

3건이 쌓이면 조건을 확정하고 `조건부 규칙`으로 승격한다.

## 16. 세 번째 자료가 들어올 때

자료가 3개 이상이 되면 이 파일의 성격이 바뀐다.

```
2개  → "두 사람이 갈리는 지점"  (조건부 규칙의 증거)
3개  → "2:1로 갈리는 지점"      (소수설이 어떤 조건에서 옳은지가 규칙)
4개+ → 어느 한 사람의 것도 아닌 문서 = 이 아카이브의 오리지널리티
```

**추가 절차**
1. 새 자료를 같은 6파일 포맷으로 처리 (`{name}/01~05`)
2. 새 SEED(예: Q-01~Q-nn) 생성
3. 이 파일의 C-01~C-12에 **새 열을 추가**한다 — 기존 판정을 지우지 않는다
4. 3자 중 2:1로 갈리면 → **소수설이 옳은 조건**을 찾는다. 그게 가장 값진 규칙이다
5. 3자 전부 같은 답 → **불변 원리로 승격.** 신뢰도 최상급

> **집계 갱신**: `## 13. 종합 표`의 분류별 집계를 갱신하고, 분기 diff에 **"불변 원리 수 / 조건부 규칙 수 / 미해결 충돌 수"**를 기록한다. **불변 원리는 늘어나기 어렵고, 조건부 규칙은 계속 늘어난다.** 그 비율이 이 아카이브의 성숙도다.
