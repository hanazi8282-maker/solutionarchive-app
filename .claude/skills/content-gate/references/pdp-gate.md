# 02. 검증 게이트 (Gate) — 프드프

> **성격**: 읽는 문서가 아니라 **통과시키는 절차**다. 초안 하나당 1회 실행.
> **파일 지도**: `README.md` / `01-methodology.md` / **`02-gate.md`(현재 파일)** / `03-excerpts.md` / `04-decisions.md` / `05-provenance.md` / `../cross-decisions.md`

---

## 0. 사용법

1. 초안을 놓고 아래 항목을 **순서대로** 묻는다. 앞에서 떨어지면 뒤는 볼 필요가 없다.
2. **떨어지면 고치는 게 아니라 돌아간다.**
3. 규칙 충돌 시 `04-decisions.md`의 P-01~P-14를 적용하고, **적용한 순간 판정 로그 엔트리를 만든다.**
4. **솔파와 갈리는 지점(`../cross-decisions.md` C-xx)을 만나면 반드시 로그를 남긴다.** 그게 이 아카이브의 최대 자산이다.
5. **역방향 모드(G-R)** — 남의 터진 콘텐츠를 넣으면 "왜 터졌는지"가 역산된다. 프드프에서는 이게 방법론의 **본체**다.

> ⚠️ **선행 조건**: 이 게이트는 **레퍼런스를 이미 분석한 상태**를 전제한다. 레퍼런스 없이 게이트에 들어오면 P-0에서 즉시 탈락이다.

## P-0. 선행 확인 — 레퍼런스가 있는가

> 프드프에서 유일하게 절대적인 항목. 원문: **"레퍼런스 없이 회의에 들어온다? 그러면 바로 빠따 맞습니다."**

| 확인 | 근거 |
|---|---|
| □ 내 분야에서 잘 터진 레퍼런스를 **실제로 열어봤는가** | §7-1, §3-2 |
| □ 그 레퍼런스의 **카피 / 도입부 3초 / 형식 / 구도 / 대본 / 행동유도 / 음악 / 댓글**을 항목별로 뜯었는가 | §7-4 |
| □ 실패한 영상(팔로워 대비 저조)을 레퍼런스로 삼고 있지 않은가 | §3-2 ④ |
| □ 레퍼런스 대본을 **필사**하고 내 것으로 **치환**했는가 (베낀 게 아니라) | §7-5 |

**떨어졌다면** → 게이트를 중단하고 `§7-2`(찾는 법) 또는 숏트렌드(`§7-3`)로 돌아간다.

## P-1. 목적 확인 — 이 계정은 터뜨려야 하는가

| 확인 | 근거 |
|---|---|
| □ 이 계정의 **목적**을 한 줄로 말할 수 있는가 (조회수 / 전환 / 브랜딩 / 소통) | §2-6, P-04 |
| □ **터지면 안 되는 계정**은 아닌가 (개인 노출형 / 고급 브랜딩) | §2-6 |
| □ 목적이 전환이라면 **조회수를 성과 지표에서 뺐는가** | §12-1 |

**원문 경고**
> **"라보 스테이크가 있어 이거는 터뜨리면 안 되거든요. 왜냐하면 고급 브랜딩적으로 가려고 하는데"**
> **"자청 제 인스타그램도 터지면 안 돼요."**

## P-2. 본능 — 어떤 욕구를 건드리는가

| 확인 | 근거 |
|---|---|
| □ **돈 / 건강 / 인간관계** 중 무엇에 걸리는가 | §5-1 |

## P-3. 표본 — 어느 층위에서 넓히고 어느 층위에서 좁히는가

| 확인 | 근거 |
|---|---|
| □ **콘텐츠 카피**는 넓혔는가 — 이 분야에 관심 없는 사람도 볼 이유가 있는가 | §2-3, C-01 ★ |
| □ 5천만 중 몇 명이 이 주제에 관심 있는지 **어림 계산**했는가 | §2-3 |
| □ **프로필 이름·소개글**은 좁혔는가 (검색 진입용 전문 키워드) | §8-4, P-03 |
| □ 표본을 넓힌 카피가 **본문 내용과 연결**되는가 (낚시가 아닌가) | §2-5 ④ |

**원문 기준**
> **"똑같은 형식으로 만들어도 똑같은 디자인으로 만들어도 조회수가 1만밖에 안 나오는 거예요."**
> **"조회수는 넓히고, 검색 진입은 좁힌다."** (P-03 판정선)

> ★ **C-01은 솔파와 프드프가 완전히 일치하는 항목이다. 여기서 떨어지면 다른 검토 없이 반려한다.**

## P-5. 가치 입증 — 후킹 다음에 믿을 이유가 있는가

| 확인 | 근거 |
|---|---|

## G-R. 역방향 모드 — 남의 콘텐츠 리버스 엔지니어링

> 프드프에서 이 모드는 부가 기능이 아니라 **방법론의 본체**다.
> 원문: **"강의에서 얻어 가야 하는 게 딱 한 가지 있다면 그건 바로 이 분석하는 습관입니다."**
> **"정말 영상을 10시간 걸려서 하나를 만드는 것보다 잘된 영상을 10개 보고 스스로 분석을 해본 다음에 한 20~30분 걸려서 하나 만드는 게 훨씬 낫습니다."**

### 대상 선정 기준

| 선정 | 제외 |
|---|---|
| **내 분야에서 100만 이상** ★ 1순위 | 실패한 영상 (팔로워 대비 저조) |
| 이유를 **모르겠는데 터진** 것 | 야한 것·노출 때문에 터진 것 |
| 같은 계정에서 **유독 잘 된 것** (평균 대비 이상치) | 이미 내가 잘 아는 형식 |
| 인접 분야 / 해외 (내 분야에 없을 때) | 팬덤·유명세로 터진 것 |

**핵심 선정 원칙(원문)**: **"터진 거를 보고 그 영상을 들어가 봐. 그러면 분명히 이 사람이 터진 이유가 존재합니다. 다른 영상들은 1~2만밖에 안 나오는데 100만이 나왔어. 여기서 분명히 배워갈 게 있어요."**

### 역방향 질문표

| 항목 | 정방향 (내 초안) | **역방향 (남의 글)** |
|---|---|---|
| **P-0** | 레퍼런스를 분석했는가 | **이 사람은 무엇을 어셈블했나** — 어떤 기존 형식을 빌려왔나 |
| **P-1** | 이 계정은 터뜨려야 하는가 | **이 계정의 목적은 뭐였나** — 조회수인가 전환인가 |
| **P-2** | 어떤 욕구를 건드리는가 | **사람들이 무의식에서 무엇을 원했나** — 돈/건강/인간관계/재미 중 |
| **P-3** | 표본을 넓혔는가 | **원래 주제는 뭐였고 어떻게 넓혔나** — Before 카피를 복원할 수 있나 |
