# 사진·로고 삭제 요청 처리 절차

사진·로고(브랜드 이미지, 제품 사진, 캡처 등)를 내려 달라는 요청이 오면 아래 순서대로 처리한다.
판단·협상하지 않는다. 먼저 내리고, 기록하고, 회신한다.

## 순서

1. **즉시 내린다.** 요청받은 대상을 노출 중인 화면·게시물에서 먼저 내린다(비공개 전환 또는 삭제).
   사실 확인·권리 여부 판단은 내린 뒤에 한다.
2. **사진 색인에서 해당 행을 지운다.** `~/sa-private/ground/ig/photo_index.csv` 에서 그 대상의 행을 삭제한다.
   이 파일은 PC 로컬 전용이고 리포에 올리지 않는다.
3. **삭제 대장에 기록한다.** 같은 폴더의 `takedown_log.csv` 에 행 1개를 추가한다. 열은 아래 6개다.

   | 열 | 내용 |
   |---|---|
   | 요청일 | 요청을 받은 날(YYYY-MM-DD) |
   | 대상 | 내린 사진·로고를 알아볼 수 있는 설명 또는 파일명 |
   | 출처 URL | 그 이미지를 가져온 원래 주소 |
   | 요청자 | 관계만 적는다(예: 브랜드 담당자, 촬영자 본인, 권리 대리인). 실명·연락처는 적지 않는다 |
   | 처리일 | 2번까지 끝낸 날(YYYY-MM-DD) |
   | 메모 | 내린 위치, 특이사항 |

4. **처리일을 기입한다.** 1·2번이 실제로 끝난 것을 확인한 뒤에만 처리일 칸을 채운다. 비어 있으면 미처리다.
5. **회신한다.** 요청이 온 경로로 "내렸다"는 사실과 처리일을 알린다.

## 지킬 것

- 이 문서와 리포에는 요청자의 실명·연락처·요청 원문을 남기지 않는다(리포는 공개다).
- `photo_index.csv`·`takedown_log.csv` 는 로컬 전용이다. 커밋하지 않는다.
- 같은 대상을 다시 올리지 않는다. 새로 수집할 때 `takedown_log.csv` 의 대상·출처 URL 과 겹치는지 먼저 본다.
