## 4. 왜 이 무브를 골랐나 (2026-09-07 재작성 — 무브가 등급 C 로 강등된 뒤)

M1 매칭 결과 TRUST 병목은 **케이스 1곳(Warby Parker)뿐**이다 — 선례축 계산에서 짝이 없다.
그런데도 이 무브를 첫 콘텐츠로 골랐다.

1. **outcome_direction 이 mixed** 다. 성공담도 실패담도 아니라서 "이렇게 하면 됩니다" 로 미끄러지지 않는다. 등급과 무관하게 유효한 이유다.
2. **근거가 전부 Warby 자신의 공시**다 — 8-K 두 건. **등급 C 인 이유가 바로 이것이다: 제3자가 이 숫자를 따로 집계·검증한 적이 없다.** 그래서 이 글은 "검증된 권위 있는 수치" 로 팔지 않는다. 회사가 스스로 낸 숫자이고 그게 우리가 가진 전부라는 사실은 **자기답글**에 둔다("Warby 자체 공시 수치다. 독립 기관이 따로 집계한 값은 없다"). 얼굴 없는 계정이 자기 이력 없이 G-5 를 통과하는 방식(자랑 대신 1차 출처)과도 맞는다.
3. **인과를 단정할 수 없다**는 것을 리서치에서 이미 잡아 뒀다(8-K 에 채널별 분해 없음, §7.1). 첫 버전은 이걸 본문에 명시했으나, 2026-09-07 리라이트에서 문체상 뺐다([[feedback-namheon-writing-voice]] 3번). 남은 신호는 "다만 … 사라지자 … 느려졌다"의 순서 서술. **인과 유보를 본문에 안 쓰는 대신 자기답글이 그 역할을 한다.**

**2026-09-07 (c 선택) 이 바꾼 것 / 안 바꾼 것**

- 바꾼 것: 본문을 사람 글로 리라이트. 게이트 용어·기호·CTA·인과유보 문장 제거. **본문이 CG-1 을 통과하지 못한다** → `posts.status='draft'`. 귀속은 자기답글에만.
- 안 바꾼 것: 소재의 값어치, 3단 서사, 인용 수치(9%→4.1%, 300곳, 30분). 등급 C 는 "이 숫자가 틀렸다" 가 아니라 "Warby 만 말했다" 이다.
