## 사고의 흐름 (1인칭, 3.5번)
- 출처: 창업자 본인 회고 https://www.derrickreimer.com/walking-away (WebFetch 2회로 직접 열람). HN 스레드가 가리키는 URL 경로상 게시일 2019-05-17.
- 흐름: 슬랙이 모든 걸 "급하게" 만든다는 관찰(Leadpages 합류 후) → 반채팅 흐름이 올 것이라는 가설 → 선언문·핸들 예약 6,000+·통화 약 40·$49 선결제 약 50 → 알파/출시 후 팀 도입 흔적 거의 없음 → The Mom Test 를 읽고 질문 방식을 바꿔 보니 "지금까지 뭘 했나"에 '아무것도' → 작은 팀은 슬랙이 약간 귀찮은 정도, 큰 팀은 성숙도 요구 → 필요 MRR $10~15k 와 혼자·자기 돈이라는 제약이 충돌 → 중단.
- 팟캐스트(Startups For The Rest Of Us ep.506, 2020-07-21) 요약 열람: 개인이 못 정하고 팀이 옮겨야 하는 문제. 요약 문장은 도구가 준 요약이라 인용이 아닌 의역으로만 썼다.

## 근거·등급
- 무브 0: 수치(6,000→50)는 창업자 회고 한 건, 자기보고. 등급 C — 다른 원 관측 없음. 사실확인 A 가 아니라 발행 불가, 사내 참고용.
- 무브 1·2: 수치 없음, 등급 D. 정상.
- 6,000→50 은 같은 깔때기의 앞뒤라 "전환율"처럼 읽히지만, 두 숫자는 서로 다른 행동(무료 예약/유료 선결제)이다. 제목·본문에 비율로 쓸 때 주의.

## 못 찾은 것 (확인 불가)
- 선결제 $49 환불 여부·코드 공개/아카이브 여부: 회고에서 확인 불가("NOT FOUND").
- 알파 10월 참여자 수, 출시 후 실제 활성 팀 수, 월 매출: 확인 불가(회고에 숫자 없음).
- Level 서비스의 현재 가동 여부: 회고 + 2021-09 HN 댓글("dead")만. 공식 종료 공지 별도 확인은 못 했다 → outcome_status=shutdown 이지만 근거는 창업자 중단 선언이다.
- 팟캐스트 요약은 후속 프로젝트 이름에 혼선(StaticKit/Mighty Cal/SavvyCal)이 있어 후속 사업 내용은 초안에 쓰지 않았다.
- 개인 사업 전 Drip 매각 금액 등 자금 규모: 확인 불가(자기 돈이라는 서술만).
