# 04. 판정 로그 (Decisions)

> **성격**: append-only. **기존 항목을 수정하지 않는다.** 판정이 틀렸으면 지우지 말고 **아래에 반증 엔트리를 추가**한다. diff가 자산이기 때문이다.
> **파일 지도**: `README.md` / `01-methodology.md` / `02-gate.md` / `03-excerpts.md` / **`04-decisions.md`(현재 파일)** / `05-provenance.md`

---

## 0. 이 파일이 존재하는 이유

`01-methodology.md`에는 서로 충돌하는 진술이 21곳 있다. 원문(솔파 강의)이 4개 연도에 걸쳐 있고, 개인 제작자 시점과 조직 시점이 섞여 있기 때문이다. **어느 한쪽을 버리면 정보가 손실되므로 둘 다 보존하고, 대신 "언제 어느 쪽을 쓰는가"의 판정선을 붙였다.**

그런데 이 판정선은 **전부 솔파의 판단을 복사한 것**이다(§`05-provenance.md` D-3-6 참조 — 원문에 명시된 판정 규칙은 하나도 없다). 그러므로 이 파일의 진짜 목적은:

```
[시작 상태]  R-01 ~ R-14 = 솔파의 판단을 추출한 규칙 (SEED)
     ↓  발행 → 성과 대조 → 반증/보강 엔트리 누적
[6개월 후]   R-xx = 내 데이터로 덮여쓰인 나의 판정선
     ↓
[diff]      SEED와 현재 상태의 차이 = 오리지널리티의 정량적 좌표
```

솔파 §2-15의 정의 — **"감이라는 건 (…) 내가 이렇게 했을 때 이 세상은 이렇게 반응하더라 (…) 이런 상호작용의 관찰이 누적된 거거든요"** — 를 무의식이 아니라 **버전 관리되는 파일**로 구현한 것이다.

## 1. 루프 프로토콜

발행 성과 대조 학습 루프에서 이 파일이 호출되는 지점은 **3곳**이다.

### 1-1. 발행 전 — 판정 기록 (필수)

`02-gate.md`를 통과시키는 과정에서 **규칙을 적용한 순간마다** 엔트리를 남긴다. 적용하지 않은 규칙은 기록하지 않는다.

기록 조건 (하나라도 해당하면 기록):
- 상충 규칙(R-01~R-14) 중 하나를 적용해 **X 또는 Y를 선택**했다
- 게이트 항목에서 **떨어질 뻔했는데 통과시켰다** (= 예외 판단)
- 규칙에 없는 새로운 판단을 했다 (→ 신규 규칙 후보)

### 1-2. 발행 후 — 성과 기입 (D+7 / D+30)

같은 엔트리에 **추가 append**한다. 원 엔트리는 손대지 않는다.

측정 지표(솔파 §9-3의 유튜브 지표를 Threads로 치환):

| 솔파 지표 | Threads 대응 | 의미 |
|---|---|---|
| 노출 클릭률 7% | **노출 대비 상호작용률** | 첫 문장(STEP 0 인사이트)이 작동했는가 |
| 시청 지속 40% | **끝까지 읽은 비율 / 저장률** | 본문이 작동했는가 |
| 비구독자 90% | **비팔로워 도달 비율** | 새 사람에게 닿았는가 |
| — | **인용·리포스트 수** | 솔파 §2-9 4번(공유 이유)의 실측치 |

### 1-2b. 역방향 트랙 (G-R) — 대기 없이 도는 루프

정방향은 D+30까지 기다려야 1건이 학습된다. 역방향은 **오늘 5건**이 가능하다.

| 트랙 | 입력 | 학습 속도 | 잡아내는 것 |
|---|---|---|---|
| **정방향** | 내 발행 → 성과 | 1건 / 30일 | 내 판정이 **맞았는지** |
| **역방향** | 남의 터진 글 | 5건 / 세션 | 내 규칙에 **구멍이 있는지** ★ |

역방향이 잡아내는 것은 정방향으로는 **원리적으로 발견 불가능**하다 — 내가 탈락시킨 글은 발행되지 않아 데이터가 남지 않기 때문이다. 절차는 `02-gate.md` G-R 참조.

**권장 비율**: 발행 1건당 역방향 3건. 초기(로그 10건 미만)에는 역방향을 더 많이 돌린다.

### 1-3. 판정 검증 — 규칙 갱신

D+30 시점에 판정의 유효성을 3택으로 마킹한다.

| 마킹 | 조건 | 후속 조치 |
|---|---|---|
| `유효` | 성과가 판정 방향과 일치 | 규칙 신뢰도 +1. 아무것도 안 함 |
| `무효` | 성과가 판정 방향과 반대 | **반증 엔트리 추가.** 규칙 본문에 예외 조항 append |
| `보류` | 다른 변수가 지배적이라 귀속 불가 | 기록만 남기고 규칙은 건드리지 않음 |

**규칙 갱신은 규칙 텍스트를 고치는 게 아니라 `## 3. 규칙 갱신 이력`에 append한다.** SEED는 영구 보존.

### R-01. 출연자빨 부정 vs A의 중요성

| | 진술 |
|---|---|
| **X** | §1-1 — **"영상은 출연자빨이 아니다. 사람의 문제가 아니라 영상의 문제입니다."** |
| **Y** | §2-1 — **"당연히 좋아요, A가 특별하면"** / 강동원 브이로그 230만 회 |

**판정선**
- **실패 원인을 귀속할 때 → X.** "소재/화자가 별로여서 안 됐다"는 진단 금지. 제작자의 미스로 처리.
- **성공 확률을 높일 때 → Y.** 좋은 A는 이득이다. 단 접근성·비용 제약이 있다.
- 최종 태도: **"출연자에 의존하지 않는다. 하지만 좋으면 땡큐다."**

**Threads 치환** — 화제성 있는 소재/인물을 끌어왔는데 반응이 없었다면, 원인은 소재가 아니라 **구성**이다.

### R-02. 메시지 부정 vs Point 필수

| | 진술 |
|---|---|
| **X** | §1-2 — **"메시지를 강조하시는 분들이 있어요. 그럼 바로 믿고 거릅니다."** |
| **Y** | §3-1 — 모든 기획안에 Point·View Point가 존재 |

**판정선**
- **Point = 독자가 느끼게 될 감상의 예측치.** 기획 단계에만 존재.
- **메시지 = 내가 본문에서 선언하는 주장.** 표면에 나오면 실패.
- **판별법**: 그 문장을 **본문 마지막 줄에 그대로 쓰면 이상한가?** 이상하면 Point(합격), 자연스러우면 메시지(위험).
- 예시: 이수영 편 Point **"오래되었다는 것은 우리의 기억일 뿐"**은 영상 안에서 아무도 말하지 않는다.

**Threads 치환** — STEP 0의 인사이트 선언은 **관찰된 사실이나 반례**여야 하고, **교훈이나 당위**여서는 안 된다.

`SEED` `신뢰도: 0` `반증: 0`

### R-06. 영원한 포맷은 없다 vs 조직엔 반복 포맷이 자산

| | 진술 |
|---|---|
| **X** | §2-12 — **"사람들이 포맷에 익숙해지는 거죠, 그래서 바꿉니다."** AOMG까지 나왔는데 100만 뷰 미달 |

**판정선**

- 원문의 자기 인식: **"저 개인이라면 전 재미가 없잖아요. (…) 그런데 조직이니까."**

### R-07. 사전 인터뷰 필수 vs 생략 가능

| | 진술 |
|---|---|
| **X** | §5-1 — **"이 사람이 어떤 말 할지도 모르는데 이런 콘텐츠에 출연시킬 수는 없습니다."** 500분 인터뷰 |
| **Y** | §5-2 — **"이건 안 해도 된다고 생각을 해서 안 했던 것 같아요."** |

- 최소선은 항상 유지: **"뭐 할지는 정해야겠죠. 어떻게 끝낼지는 정해야겠죠 기승전결을."**

**Threads 치환** — 자료조사/사실확인의 생략 판정선. 소재를 이미 몸으로 아는가, 포맷이 검증됐는가, 첫 문장만으로 끝나는가.

## 6. diff 산출 방법 (분기 1회)

오리지널리티의 정량적 좌표를 뽑는 절차. 분기마다 실행.

1. `## 3. 규칙 갱신 이력`의 엔트리 수를 센다 → **덮여쓰인 규칙 수 / 14**
2. `## 5. 신규 규칙 후보` 중 승격된 것을 센다 → **원문에 없던 나의 규칙 수**
3. `## 4. 판정 로그`에서 `출처: 자체발행` 엔트리의 규칙별 `유효 / 무효` 비율을 낸다 → **규칙별 신뢰도**
4. `출처: 외부관찰` 엔트리 중 **결론이 `구멍`**인 건수를 센다 → **규칙의 사각지대 규모**
5. 아래 표를 갱신한다.

| 분기 | 덮여쓴 규칙 | 신규 규칙 | 자체발행 | 외부관찰 | 유효율 | 구멍 발견 | 메모 |
|---|---|---|---|---|---|---|---|
| 2026 Q3 | 0 / 14 | 0 | 0 | 0 | — | 0 | SEED 상태 |

> **해석 기준**
> - 유효율 높음 + 갱신 0 → 솔파의 판단이 내 영역에서도 통한다
> - 유효율 낮음 + 갱신 0 → ⚠️ **루프가 안 돌고 있다**(기록만 하고 반영 안 함). 최악의 실패 모드
> - 자체발행 ≫ 외부관찰 → 학습 속도가 D+30에 묶여 있다. G-R를 늘려야 한다
> - 구멍 발견이 계속 0 → 대상 선정이 안전한 쪽으로 쏠려 있다. **"이유를 모르겠는데 터진 것"**을 골라야 한다
