# 00. 통합 게이트 — 솔파 × 프드프

> **성격**: 매체와 무관하게 **먼저 통과시켜야 하는 공통 관문** + 매체별 분기.
> **위치**: `methodology/content/00-gate.md` (두 폴더의 상위)
> **참조**: `solfa/02-gate.md`(G-0~G-10, G-R) / `pdp/02-gate.md`(G-0~G-13, G-R) / `cross-decisions.md`(C-01~C-12)

---

## 0. 이 파일이 존재하는 이유

솔파 게이트(G-0~G-10)와 프드프 게이트(G-0~G-13)를 초안 하나에 둘 다 돌리면 **중복이 크다.** 그런데 둘을 그냥 합칠 수도 없다 — 같은 질문에 다른 답을 하는 지점이 있기 때문이다.

`cross-decisions.md`의 판정 결과가 이 문제를 해결한다.

```
[Ⅰ] 공통 관문   ← C-01, C-08, C-12 (도메인 불변 원리 3건)
        ↓        여기서 떨어지면 매체와 무관하게 폐기
[Ⅱ] 조건 분기   ← C-03, C-05, C-07, C-10, C-11 (조건부 규칙 5건)
        ↓        소비 환경·숙련도·목적에 따라 어느 쪽을 쓸지 결정
[Ⅲ] 매체별 게이트 ← solfa/02-gate.md 또는 pdp/02-gate.md
        ↓
[Ⅳ] 충돌 로깅   ← C-02, C-04, C-06 (미해결 충돌 3건)
                 판단할 때마다 반드시 기록
```

**사용 원칙**
- Ⅰ은 **모든 초안**이 통과해야 한다. 예외 없음.
- Ⅱ에서 어느 쪽 규칙을 쓸지 결정한 뒤 Ⅲ으로 내려간다.
- Ⅲ은 **한쪽만** 돈다. 둘 다 돌지 않는다.
- Ⅳ를 만나면 **판정하고 기록**한다. 기록이 이 아카이브의 유일한 학습 입력이다.

# Ⅰ. 공통 관문 — 매체 무관 3항목

> `cross-decisions.md`에서 **두 방법론이 완전히 일치**한 항목이다. 매체·목적·시대가 전부 다른데 같은 답이 나왔다.
> **여기서 떨어지면 다른 검토 없이 반려한다.**

## U-1. 타깃 — 이 분야에 관심 없는 사람도 볼 이유가 있는가 `[C-01]`

| 확인 | 솔파 근거 | 프드프 근거 |
|---|---|---|
| □ 이 분야에 **관심 없는 사람도 볼 이유**가 있는가 | R-11, §2-13 | §2-3 표본 이론 |
| □ 조건을 곱하고 있지 않은가 (X에 관심 있고 + Y도 알고 + Z까지 겪은 사람만) | §2-13 | §2-3 |
| □ 5천만 중 **몇 명이 이 주제에 관심** 있는지 어림 계산했는가 | — | §2-3 |
| □ 소재가 마이너한 건 괜찮다. **그 업계 사람만 이해하는 글**이 아닌지만 본다 | R-11 | §12-1 |

**두 원문의 같은 실패 진단**
> 솔파: **"'난 인사담당자야' 하면서 막… '꿀팁!' (…) 그러면 안 됩니다. 이거를 여세요."**
> 프드프: **"사이코패스를 찾고 싶은 사람이 그렇게 많지 않단 말이에요."** → 1만 → 110만

**떨어졌다면** → 소재를 바꾸거나 §2-13(솔파 확장 4가지) 또는 §2-3(프드프 표본 치환)으로 되돌아간다. **카피만 고쳐서는 안 된다.**

> ⚠️ **예외 조건(양쪽 공통)**: 이미지·감성으로 승부하는 형식(모델·풍경·음식 클로즈업)은 표본 계산이 불필요하다. 솔파 §8-3(호박벌), 프드프 §2-3 ④.

## U-2. 구조 — 달려가는 지점 = 해소 구간이 하나로 특정되는가 `[C-12]`

| 확인 | 솔파 근거 | 프드프 근거 |
|---|---|---|
| □ 이 콘텐츠의 **가장 뾰족한 한 지점**이 어디인지 말할 수 있는가 | §3-9 콘텐츠 각 | §5-7 해소 구간 |
| □ 나머지가 **그 지점을 향해 달려가는가** (평평하게 나열되어 있지 않은가) | §3-9 | §7-7 |
| □ 잘라내서 단독으로 성립하는 **조각**이 있는가 | §3-3, §9-4 | §1-2 (저장·공유 단위) |
| □ 서사라면 **안 좋았던 상황 → Key → 결과** 3단이 있는가 | §3-1 | §3-10 |

**두 원문의 같은 표현**
> 솔파: **"실제 영상은 10분이고 술 취한 사람이 나오는 건 한 30초 정도밖에 안 되지만"** — 나머지는 그 30초를 위해 존재한다
> 프드프: **"여기서 보면서 느꼈던 감정이 딱 해소가 되는 구간이 있으면 터진 거예요."** — 청담 스테이크 **"7만 6천 원"**

**떨어졌다면** → 지점이 둘 이상이면 하나로 줄이고, 없으면 기획으로 되돌아간다.

## U-3. 관찰 — 이 판단이 관찰에서 나왔는가 `[C-08]`

> 이 항목은 초안 검증이 아니라 **상시 습관 점검**이다. 주 1회 확인한다.

| 확인 | 솔파 근거 | 프드프 근거 |
|---|---|---|
| □ 이번 주에 남의 콘텐츠를 **실제로 분석**했는가 (몇 건) | §1-10, §12-4 | §3-2, §7-1 |
| □ 그 분석이 **댓글·반응 실물**에 근거하는가 (내 추측이 아니라) | §1-10 | §7-4 |
| □ 관찰한 것을 **기록**했는가 | §2-15 | §3-2 |
| □ 이번 초안의 판단이 그 기록에서 나왔는가 | — | §3-2 |

**두 원문의 같은 결론**
> 솔파: **"감은 마법이 아닙니다. 일상에서 무의식적으로 축적된 '데이터의 합'입니다."**
> 프드프: **"사실 여러분이 이 강의에서 얻어 가야 하는 게 딱 한 가지 있다면 그건 바로 이 분석하는 습관입니다."**

**떨어졌다면** → 초안을 멈추고 역방향(G-R) 세션을 먼저 돈다.

> ⚠️ **최대 실패 모드**: 아카이브는 만들어놓고 관찰을 안 하는 것. 두 원문이 유일하게 완전히 합의한 항목이 관찰이다.

# Ⅱ. 조건 분기 — 어느 쪽 규칙을 쓸 것인가

> `cross-decisions.md`에서 **조건이 확정된** 5건이다. 표를 조회해 답을 정한 뒤 Ⅲ으로 내려간다.

## D-1. 초반 몇 초를 얼마나 조일 것인가 `[C-03]`

| 조건 | 적용 | 근거 |
|---|---|---|
| **소비 환경이 스크롤 피드** (Threads·릴스·쇼츠·틱톡) | **프드프.** 1초 안에 인식되게 한다. 도입부에 가장 오래 고민 | 프드프 §3-8 |
| **소비 환경이 클릭 후 진입** (유튜브 롱폼·블로그·뉴스레터·상세페이지) | **솔파.** 썸네일·제목이 이미 그 역할을 했으므로 도입부는 유연 | 솔파 §1-12 |
| **판단이 안 설 때** | 소비 태도를 먼저 측정한다 — 돈을 내는가 / 멈출 수 있는가 / 소리를 키는가 / 누워서 보는가 | 솔파 §11-1 |

> **Threads 기본값 = 프드프.** 스크롤 피드이므로 첫 문장에 가장 오래 고민한다.

---

## D-2. 레퍼런스를 어디서 가져올 것인가 `[C-05]`

> ★ 두 원문 중 어느 쪽도 명시하지 않은 **통합 원칙**이다.
> **"아직 이 시장에서 소모되지 않은 형식을 가져온다."**

| 조건 | 적용 |
|---|---|
| **기본기 미완성 / 이 분야 형식을 아직 모름** | **프드프.** 내 분야·같은 플랫폼에서 100만 이상부터 |
| **내 분야는 이미 다 봤다 / 차별화 단계** | **솔파.** 다른 매체(영화·vimeo) + 프드프의 해외 레퍼런스 |
| **형식이 이미 포화된 카테고리** | 다른 매체 |
| **레퍼런스가 아예 없는 좁은 분야** | 인접 분야로 확장 (누수탐지 → 인테리어·청소) |

> 프드프의 **해외 레퍼런스**(§7-2)와 솔파의 **다른 매체**(§8-6)는 구조적으로 같은 것이다 — 둘 다 "이 시장에서 아직 안 쓴 형식".

---

## D-3. 현실 연결을 어떻게 검증할 것인가 `[C-07]`

> 상보적이다. **3단계로 순서대로 돈다.**

```
1단계 (프드프): 돈 / 건강 / 인간관계 중 어디에 걸리는가?
                → 걸리지 않으면 하위 욕망일 가능성 높음 (효도 생선구이 1만)
2단계 (솔파):   그 욕구가 "이 아이디어가 나오기 전에 이미 있던 현실"인가?
                → 사후 정당화 차단
3단계 (프드프): 표면 주제가 아니라 근원 이득까지 내려갔는가?
                → 살림 꿀팁 → "매일 500원씩 아끼는" / 동치미 해독 → 다이어트
```

---

## D-4. 시간을 얼마나 쓸 것인가 `[C-10]`

> 2단 판정선. 솔파 기준만 쓰면 과투입, 프드프 기준만 쓰면 인지되는 요소를 놓친다.

```
1차 (솔파):   독자가 이 차이를 인지하는가?
              → 인지 못 하면 즉시 중단 (4K, 프로레스, 정밀 색보정)
2차 (프드프): 인지한다면, 목적이 도달인가 전환인가?
              → 전환이 목적이면 인지되더라도 최소화
```

| 목적 | 투입 | 근거 |
|---|---|---|
| **조회수 200~300만** | 편집·나레이션·전환 효과 투입 | 프드프 P-08(Y) |
| **전환·문의** | 최소. 캡션형·템플릿으로 | 프드프 P-08(X), §11-3 |
| **독자가 인지하는 요소**(BGM·표정·대사·조명 방향) | 무제한 | 솔파 R-13 |

## D-5. A(화자·출연자)에 어떤 라벨을 붙일 것인가 `[C-11]`

> 두 종류를 **다 붙일 수 있다.**

| 라벨 | 목적 | 적용 |
|---|---|---|
| **권위 라벨** (프드프 §4-8) | 신뢰 · 반박 차단 | 정보형 콘텐츠에 필수 |
| **계층·상황 라벨** (솔파 §2-2) | 감정 이입 | 서사형 콘텐츠에 필수 |
| **둘 다** | 언매칭 발생 | 예: "13년차 피부과 전문의인데 정작 내 피부는 망가져 있었다" |

> 프드프의 **언매칭**(§3-13)이 사실 이 결합의 한 형태다: **"나는 서울대지만 평생 책 한 권도 읽지 않는다"** = 권위 라벨 + 상반된 상황.

# Ⅳ. 충돌 로깅 — 판단할 때마다 기록

> `cross-decisions.md`에서 **조건이 아직 확정되지 않은** 3건이다.
> **이 지점을 만나면 반드시 로그를 남긴다. 이게 이 아카이브에서 가장 값진 데이터다.**

## X-1. 감 · 재능 `[C-02]`

**만나는 순간**: "공식대로 했는데 왜 안 되지?" 또는 "이건 공식으로 안 될 것 같은데"

| 솔파 | 프드프 |
|---|---|
| 격차는 못 따라잡는다. 목표는 재앙 회피 | 14공식으로 초고수. 일주일 |

**조건 초안(미검증)**: 변수가 적은 매체 → 공식으로 상위권 / 변수가 많은 매체 → 공식은 하한선만. **그리고 반복 재현은 양쪽 다 공식만으로 안 된다.**

**로그 기입 항목**: 어느 쪽을 택했는가 / 이 콘텐츠의 변수 개수 / **예측**(공식대로 하면 어느 수준까지 나올 것인가)

---

## X-2. 알고리즘 `[C-04]`

**만나는 순간**: 발행 직후 무언가를 더 할지 말지

| 솔파 | 프드프 |
|---|---|
| 최적화 없다. 태그도 안 검 | 반응률 설계 + 업로드 직후 학습 작업 |

**합의된 부분**: **콘텐츠 품질이 전제 조건**이라는 것은 양쪽 같다.
**갈리는 부분**: 그 위에 조작을 얹을 것인가. **프드프 내부에서도 P-13으로 충돌한다.**

**실측 설계(권장)**: 같은 품질의 글 10건 중 5건은 업로드 직후 반응 작업, 5건은 아무것도 안 함 → 초기 도달 비교.

**로그 기입 항목**: 작업을 했는가 / 안 했는가 / 초기 1시간 도달

---

## X-3. 연출 vs 주작 `[C-06]`

**만나는 순간**: 경험담을 각색하거나, 내 상품을 남의 시점으로 쓸 때

| 솔파 R-14 | 프드프 P-14 |
|---|---|
| 느끼지 않은 감정을 말하게 하지 않는다 + 사전 동의 | 후기성 프레이밍 허용 + 출처 표기 권고 |

**재해석**: 다른 종류의 위험을 다룬다. 솔파 = **타인 인격**(윤리) / 프드프 = **소비자 기만**(법·신뢰). **둘 다 필요하다.**

**통합 판정선 초안**
```
① 타인이 등장하면        → 솔파 R-14 적용 (감정의 진위 + 사전 동의)
② 내가 광고 주체이면      → 프드프 P-14 + 출처 표기 강화
③ 둘 다 걸리면            → 더 엄격한 쪽
④ 공통 최저선            → 사실(숫자·이력·후기)은 실제여야 한다
```

**로그 기입 항목**: 타인 등장 여부 / 광고 주체 여부 / 어디까지 각색했는가 / 독자 거부반응 유무

# Ⅴ. 로그 — 판정을 기록했는가

| 확인 | 대상 파일 |
|---|---|
| □ Ⅲ에서 적용한 규칙(R-xx / P-xx)을 로그에 남겼는가 | `solfa/04-decisions.md` 또는 `pdp/04-decisions.md` |
| □ Ⅱ에서 조건 분기를 했다면 어느 쪽을 왜 택했는지 남겼는가 | 해당 04 + `cross-decisions.md` |
| □ **Ⅳ의 충돌을 만났다면 반드시 기록했는가** ★ | `cross-decisions.md` `## 15. 교차 갱신 이력` |
| □ **예측**을 기입했는가 | 04 §4 |
| □ 엔트리에 `출처`(자체발행/외부관찰)와 `방법론`(솔파/프드프/교차) 플래그를 달았는가 | 04 §4 |

> **예측 없이 발행하면 D+30에 아무것도 학습되지 않는다.**

# Ⅵ. 역방향 모드 — 두 게이트를 동시에 돌린다

> 남의 터진 콘텐츠를 넣을 때는 **양쪽 게이트를 다 돌린다.** 이게 정방향과의 결정적 차이다.

## 절차

1. 대상 선정 — `pdp/02-gate.md` G-R 또는 `solfa/02-gate.md` G-R의 기준
2. **Ⅰ의 3항목**을 역방향으로 묻는다
   - U-1 → 이 글은 **어느 계층까지 닿았나**. 관심 없는 사람이 반응했나
   - U-2 → **어느 문단이 잘려 인용됐나 / 어디서 감정이 해소됐나**
   - U-3 → (해당 없음. 이 작업 자체가 U-3이다)
3. **매체에 맞는 쪽**의 G-R 질문표를 채운다 — 댓글·인용문 실물로
4. **핵심 판정 2개를 낸다** ★
   ```
   □ 솔파 게이트로 이 글을 탈락시켰겠는가?  (예 / 아니오 / 어디서)
   □ 프드프 게이트로 이 글을 탈락시켰겠는가? (예 / 아니오 / 어디서)
   ```
5. 결과 처리

| 결과 | 의미 | 처리 |
|---|---|---|
| 둘 다 통과 | 두 규칙과 정합 | 신뢰도 +1 |
| 둘 다 탈락 | ★ **양쪽 규칙에 공통 구멍** | 최고 가치. 신규 규칙 후보 |
| **한쪽만 탈락** | ★★ **조건부 규칙의 증거** | `cross-decisions.md` 갱신 대상 |

> **"한쪽만 탈락"이 이 통합 게이트를 만든 이유다.** 단일 게이트로는 원리적으로 발견할 수 없다.
