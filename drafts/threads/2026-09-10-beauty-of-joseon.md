이 역할(sa-cmo-writer)의 도구는 Read/Grep/Glob/Write뿐이라 `case_moves.evidence_grade`를 DB에서 직접

- `source_tier === 'primary'`인 근거 없음 → `nonSelfPrimary = 0` → A(비자기보고 1차) 경로 탈락
- `corroborating`(자기보고 아님 + 추정 아님 + primary/secondary) = 더브이씨·더벨·뉴스1 3건(데일리안은 `is_self_reported: true`라 제외)

- `estimates`(is_estimate=true) = 0건 → 마지막 분기로 낙착: **`grade: 'C'`, reason: "교차 확인 없음 — 근거 4건 / 독립 원 관측 0개 (교차 확인 후보 3건 중 3건은 관측 키·수치 뒷받침 미기재라 세지 않았다)"**

## CG-1 검증 — 귀속 문구가 본문에 있는가

`lib/cases/publish-gate.ts`의 `attributionGate`는 두 경로 중 하나로 통과시킨다: (1) `SELF_MARKERS`
정규식(예: `공시\s*(기준|...)`), (2) 브랜드명 + 25자 이내 귀속 동사(`밝힌/밝혔/발표한...`).

이 역할은 Bash가 없어 `attributionGate`를 실제로 실행하지 못했다(스킬 문서가 코드 실행 도구를 주지 않음
— **확인 불가**를 양성으로 접지 않는다는 원칙에 따라, 대신 두 정규식을 손으로 문자열에 대입해 추적했다):

1. 본문 3문단 "전자공시 **기준**으로 보면" — `전자공시` 안의 `공시` + 공백 + `기준`이 `(공시|...)\s*(기준|...)`
   패턴과 정확히 일치(`공시 기준`이 부분 문자열로 존재). **SELF_MARKERS 매치.**
2. 같은 문단 "**조선미녀**가 협업 기사에서 **밝힌** 바 있다" — 브랜드명 뒤 25자 이내에 `밝힌`이 있어
   이름 귀속 경로도 별도로 통과. (1)이 이미 통과시키므로 이건 이중 안전장치.

두 경로 모두 실제 실행이 아니라 **손 추적**이라는 점을 명시한다. 정규식 자체는 `lib/cases/publish-gate.ts`
원문을 그대로 읽어 옮긴 것이라 로직 자체를 잘못 읽었을 위험은 낮지만, "돌려봤다"와 "읽고 손으로 맞춰봤다"는
다른 확인 방법이다(CLAUDE.md §7.1 — 검사 방법이 주장과 같은지 확인하라).

