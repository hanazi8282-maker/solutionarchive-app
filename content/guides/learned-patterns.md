# 검증된 패턴 (자동 생성)

> ⛔ 이 파일은 나이틀리 인사이트 루프가 통째로 덮어쓴다.
>    사람이 직접 고치면 다음 실행에서 사라진다.
>    사람이 쓰는 가이드는 voice-guide / seo-guide / viral-patterns 쪽이다.
>
>    출처: 사용자가 저장한 Threads 글에서 추출된 패턴 중,
>    실제 발행 성과로 검증됐거나 검증 대기 중인 것.
>    생성 로직: lib/insight/patterns.ts, 실행: .github/workflows/nightly-insight-loop.yml

강조 수준은 실측 성과로 정해진다:

- **기본값** — 답글률 개선이 반복 확인됨. 특별한 이유가 없으면 이대로 쓴다.
- **권장** — 개선이 확인됨. 소재에 맞으면 우선 고려한다.
- **참고** — 근거는 모였으나 성과 검증 대기 중. 참고만 한다.

## 자기판정 역설훅

- **강조 수준**: 참고
- **근거 수**: 저장 글 2건
- **인사이트 유형**: reframe
- **연결된 가설**: H8
- **패턴 키**: `self-admission-contradiction-hook`

① 캐주얼한 경보성 문구('큰 거 온다..')로 훅을 열어 호기심 유발 → ② 발화 주체를 회사 자신으로 못박아 신뢰도를 높임('오픈AI가 자기 손으로 최고 위험 등급을 확정') → ③ 같은 문장 안에서 즉시 모순을 배치('그러면서... 출시하겠다고') → ④ 추상적 등급을 체감 가능한 구체 행위로 번역('사람 개입 없이 제로데이를 찾아 공격 코드까지 만드는')하고 날짜(9월 1일)로 사실성 고정 → ⑤ 모순이 어떻게 해소됐는지 설명하며 반전 제공('능력을 깎는 대신 거부율과 정렬, 감시를 올려') → ⑥ '정리했습니다 🧵'로 스레드 이어보기 유도하며 마무리.

왜 통하는가: 1차 발화자(회사 본인)가 스스로 위험을 인정하고도 상반된 행동을 한다는 모순은 외부 비판보다 신뢰도와 긴장감이 높고, 추상적 위험 등급을 구체적 능력 묘사로 즉시 번역해 독자가 심각성을 체감하게 만든다.

## 반전형 겸손 마무리

- **강조 수준**: 참고
- **근거 수**: 저장 글 2건
- **인사이트 유형**: transferable_frame
- **연결된 가설**: H9
- **패턴 키**: `stereotype-reversal-anecdote-reflection-close`

훅 방식: '고령·부유층·비IT업종 인물이 신기술을 능숙히 쓴다'는 통념 파괴형 감탄사로 시작(자기 고백이 아니라 제3자에 대한 반전 진술). 전개 순서: (1) 장소·상황을 구체적으로 제시해 사실성 확보(포르투갈, 요트, 아침식사) → (2) 대조군을 명시적으로 병치해 반전의 낙차를 키움('한국 젊은 기업가'도 못 하는 걸 '프랑스 60대 할아버지'가 함) → (3) 인물의 직접 발화를 인용해 구체적 사용 성과 제시(코워크로 30명 감원) → (4) 학습법(페이스북 글 적용)과 삶의 철학(행복 우선, 기버 마인드)을 순차적으로 덧붙여 증거를 누적시킴. 마무리 형태: 질문이나 행동지시 없이 '우물안 개구리임을 다시 느낌'이라는 화자 자신의 자기반성적 단언으로 닫음.

왜 통하는가: 통념을 깨는 제3자 일화로 호기심을 자극한 뒤 구체적 디테일(사용법→학습법→삶의 철학)을 층층이 쌓아 신뢰를 만들고, 마지막에 화자가 스스로 겸손해지는 모습을 보여줌으로써 독자도 답을 강요받지 않고 자연스럽게 같은 반성에 이입하게 만든다.
